# 修仙世界觀設定庫

修仙／武俠類遊戲的世界觀筆記，用 Obsidian 管理。

這裡只收**類型通用的公共概念**：修煉境界、五行、法則、天劫、靈根、神獸等。這些大多出自道教、佛教、五行學說與《山海經》等古籍，或已是整個仙俠類型共用的慣例，可以自由使用並自行改造。

特定小說專屬的人物、道具、勢力名稱和劇情不收在這裡，見 [[避免照搬清單]]。

## 用 Obsidian 開啟

1. 把這個 repo clone 到本機。
2. Obsidian 啟動畫面 → 「開啟資料夾為儲存庫」→ 選 clone 下來的資料夾。
3. 從 [[00-索引]] 開始看。

## 結構

- `概念/`：通用的類型概念，每個主題一篇
- `設計/`：把概念轉成遊戲系統的筆記，以及 IP 注意事項
