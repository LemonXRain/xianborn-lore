# 魂牌與令牌

把精血、分魂或權限「做成一塊牌子」，是修仙世界管理人與空間的基本工具。魂牌管的是**生死與人身**，令牌管的是**身分、通行與號令**。一塊牌子在誰手上，往往就決定了誰聽誰的。

## 魂牌（本命牌、命牌、魂燈）

以修士的一縷分魂加一份精血，用秘術煉製而成（見 [[精血與煉化]]、[[分魂與化身]]）。

| 功能 | 說明 |
| --- | --- |
| 生死感應 | 本人死亡，魂牌碎裂或靈光熄滅；魂燈則是燈滅 |
| 追查兇手 | 宗門看到魂牌碎了，就派人調查、追殺兇手，執法機構也會追究責任 |
| 控制人身 | 魂牌扣在別人手上，本人就被綁住，例如離不開某個地方，要取回魂牌才自由 |
| 寄放分魂 | 有些魂燈類法寶能盛放、溫養分魂，當作保命後手 |

**類型慣例**：
- 加入宗門、家族、勢力時留下魂牌，是常見的入門程序，也是忠誠的保證。
- 沒有留下本命之物的人，別人就無法判斷他的生死，失蹤者的生死成謎。
- 魂牌被認為極少出錯；魂牌碎了卻不相信人會死，常是懸疑劇情的開端。

## 令牌

| 類型 | 用途 | 常見例子 |
| --- | --- | --- |
| 身分令牌 | 證明身分與職位，常滴精血認主 | 長老令、客卿令、弟子令、城市居住指環 |
| 禁制令牌 | 開關某處禁制，自由出入 | 洞府、藥園、密室的通行牌；租用到期會被收回 |
| 秘境令 | 進入秘境的鑰匙與名額 | 某些令牌一枚能帶多人入場，成為勢力爭奪對象（見 [[秘境]]） |
| 號令類 | 召集、指揮、宣告 | 召集妖族的號令、追殺令、通緝令、懸賞令 |
| 控制令牌 | 承載控制他人的禁制 | 以精血種下禁制，綁在令牌上，令牌毀了控制就斷 |
| 傳訊類 | 遠距離傳話 | 傳音符、傳訊玉牌 |

**令牌的特性**：
- **權限綁物**：誰拿著令牌誰就有權限，所以令牌會被偷、被搶、被偽造。
- **認主**：重要令牌會滴精血認主，別人搶走也用不了。
- **有期限**：租來的、借來的令牌到期會被收回。
- **可交易**：秘境令、名額令是可以買賣的資源（見 [[拍賣會與交易]]）。

## 交出魂牌，等於交出性命
- 被俘、投降、加入大勢力時被要求留下魂牌，是「受制於人」的開始（見 [[從屬與手下]]）。
- 魂牌被扣著的人，會想盡辦法取回或銷毀它，這是很好的劇情動機。
- 反過來，假死騙過魂牌、讓魂牌碎裂但人還活著，是類型中常見的脫身手法。

## 遊戲化點子
- **加入勢力要留魂牌**：好處是死了會有人替你報仇、宗門會追查；壞處是你被綁住，叛逃代價很高。
- **魂牌碎裂事件**：NPC 的魂牌碎了，觸發調查任務，追查兇手。
- **奪回魂牌**：被扣住魂牌的 NPC 求玩家幫忙取回，換取效忠或報酬。
- **令牌鑰匙系統**：洞府、藥園、秘境都用令牌開啟，令牌可以租、借、搶、偽造。
- **秘境令爭奪**：一枚令牌能帶幾個人入場，各勢力爭搶或拉攏持令人。
- **通緝令**：玩家被通緝時，城市守衛與賞金獵人會追殺，見 [[隱匿與追蹤]]。
