# 壽元與天人五衰

壽元是修仙世界裡最公平的壓力：再強的人也會老死。突破境界的最大動機往往不是變強，而是**活下去**。境界與壽元上限見 [[修煉境界]]。

## 壽元的常見規則
- **境界決定壽元上限**：每過一個大境界，壽元大幅延長，數字自己定。
- **卡關等於等死**：困在瓶頸的老修士眼看壽元耗盡，最容易鋌而走險。
- **壽元會被消耗**：燃燒精血、施展禁術、強行催動法寶都可能折損壽元，見 [[精血與煉化]]。
- **駐顏**：外貌可以停在某個年紀，跟真正的壽元是兩回事。
- **仙凡之隔**：修士活得比凡人親友久太多，見 [[凡俗世界]]。

## 延壽的手段

| 手段 | 說明 | 代價 |
| --- | --- | --- |
| 突破境界 | 最正統的延壽方式 | 要過天劫，見 [[天劫與心魔]] |
| 延壽丹藥 | 加若干年壽元，通常有服用上限 | 稀有、高價，見 [[煉丹與丹方]] |
| 天材地寶 | 萬年靈藥、靈果 | 要搶，往往在秘境，見 [[秘境]] |
| 奪舍 | 換一具年輕的肉身 | 損傷神魂、天道不容，見 [[分魂與化身]] |
| 轉修鬼道 | 捨棄肉身以魂體存續 | 從此怕陽氣雷火 |
| 封印沉眠 | 自我封印、降低消耗 | 醒來時世界已經變了 |

## 壽盡的結局
- **坐化**：壽元耗盡、安然而逝，常留下遺府、遺寶或傳承，是秘境與洞府的主要來源。
- **尸解**（道教）：捨棄肉身而成仙的方式，又分兵解（借兵刃）、水解、火解等。可以做成「死亡不是終點」的特殊結局。
- **身死道消**：肉身與神魂一起消散，最徹底的死。

## 天人五衰（佛經）
佛經說天人壽命雖長，壽盡時仍會出現五種衰相：
1. 衣裳垢膩：衣服變髒
2. 頭上花萎：頭上的花冠枯萎
3. 腋下汗出：腋下流汗
4. 身體臭穢：身體發出臭味
5. 不樂本座：坐不安穩，不喜歡自己的座位

意思是連天人都逃不過無常。仙俠作品常借來當作**仙人的壽命關卡**：成仙不等於永生，到了某個階段要一衰一衰地抵抗。五衰的內容和對應境界可以自己重新設計。

> 自己設計時，保留「五衰」這個公共的框架，不要套用特定作品把五衰改寫成哪五種、各對應哪個境界的那一組設定（見 [[避免照搬清單]]）。

## 遊戲化點子
- **壽元倒數**：角色有壽元條，閉關、趕路、受重傷都會消耗，逼玩家安排優先順序。
- **壽元當貨幣**：燃燒壽元換一次爆發，或用壽元換情報、換交易。
- **老怪物的動機**：壽元將盡的 NPC 會為了延壽丹不擇手段，是現成的反派或任務來源。
- **坐化遺府**：每個坐化的高手都留下一座可探索的洞府。
- **五衰 Boss 戰**：每一衰做成一場試煉，過不了就掉境界或壽元。
- **傳承與子嗣**：角色壽盡後由弟子或後代接手，做成世代傳承的玩法。
