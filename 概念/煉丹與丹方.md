# 煉丹與丹方

煉丹源自道教外丹術。在修仙作品裡，丹藥是突破境界的關鍵，而**丹方**（配方）比丹藥本身更珍貴：有方才能煉，沒方再多材料也沒用。

## 丹方的價值（類型慣例）
- 丹方是宗門、丹師「珍若性命」的私藏，輕易不外傳。
- 常見取得方式：師門傳授、拿稀有靈草交換、拍賣、秘境、古籍殘卷。
- **古方**：失傳的丹方，可能缺材料或缺步驟，要自己補完。
- **改良方**：用替代材料取代稀缺主材，例如用妖獸內丹代替只在秘境生長的靈藥，效果略差但能量產。

## 丹方的結構

| 部分 | 說明 |
| --- | --- |
| 主材 | 決定丹藥效果的核心靈藥，通常最稀有 |
| 輔材 | 調和藥性、降低毒性 |
| 藥引 | 引發藥效的觸媒 |
| 年份要求 | 靈藥需達到某個年份（見 [[修仙資源]]） |
| 火候 | 火的種類與控制，如凡火、地火、靈火、真火 |
| 手法 | 投藥順序、時間、法訣 |

## 丹藥的功能分類
各作品的丹藥按用途分，結果幾乎都落在這幾類：

| 類別 | 作用 | 常見規則 |
| --- | --- | --- |
| 修煉 | 增加靈力、加快吐納 | 依境界分階，越高階越貴；常有服用次數或間隔限制 |
| 突破 | 幫忙衝破大境界瓶頸 | 最有價值的一類，一個大境界一種 |
| 療傷、解毒 | 止血、續命、逼毒、避毒 | 避毒丹可以事先服用，用來進毒霧區 |
| 神魂 | 修補神魂、增強神識 | 見 [[神魂神通]] |
| 壽元、駐顏 | 延壽、留住容貌 | 延壽丹通常品級很高，見 [[壽元與天人五衰]] |
| 壓制 | 壓住煞氣、心魔、毒氣 | 多半治標不治本，見 [[煞氣與濁氣]] |
| 戰鬥增益 | 短時間暴增法力或肉身 | 藥效一過就虛弱，要休養 |
| 禁藥 | 燃燒精血、根基換一次爆發 | 可能折壽、掉境界，見 [[精血與煉化]] |
| 害人 | 毒殺、控制、懲處 | 見下 |
| 特殊 | 替死、易容、隱藏氣息等 | 自由發揮 |

### 害人的丹藥
丹藥不只救人。常見的害人用途：
- **毒丹**：讓人無聲無息死去，或一入口必死。對凡人和低階修士最有效，高階修士能逼毒。
- **控制丹**：讓人服下後定期要解藥，不然毒發；或直接迷失心智、聽命於人。這是類型作品很常見的控制手段，見 [[控制手段]]。
- **賜死與懲處**：上位者賜丹，下位者只能當場服下，是很有張力的劇情橋段。
- **以人入藥**：魔道用活人或修士當煉丹材料，是反派的標誌性惡行。
- **假丹、廢丹**：以次充好或暗中下毒，用在交易詐騙，見 [[拍賣會與交易]]。

## 煉丹的變數
- **丹爐**：好的丹爐提高成功率，有些丹爐本身是法寶。
- **火**：火越強越純，能煉的丹越高階；稀有的「異火」是珍寶。
- **成丹率**：一爐可能成數顆，也可能全廢。
- **品質**：同一張丹方也能煉出不同品質。
- **丹毒**：吃太多丹藥會累積丹毒，影響後續修煉。
- **丹劫**：極品丹藥成丹時引來天劫，見 [[天劫與心魔]]。丹還沒穩固就被劈中會潰散；撐過丹劫的丹品質更好。丹劫聲勢大，容易引來旁人搶丹。
- **爆丹**：火候失控時，丹藥在成形前炸散，整爐材料作廢。
- **成功率**：越高階的丹越低，好幾份材料才成一顆是常態，所以材料要多備。

## 丹火與火靈助煉
火是煉丹最重要的變數之一。最高級的做法不是自己催火，而是**召出火靈幫忙煉丹**：
- 火靈（火鳥、火焰小人等，見 [[異火與冰火]]）坐在爐底，把自身火焰分成好幾股，均勻包住丹爐。
- 修士就能專心投藥、打法訣、控制材料平衡，不必分心維持火候。
- 火靈的火越強，能煉的丹越高階；火靈成長，煉丹能力也跟著成長。
- **猛火催丹**：爐火突然暴漲能讓丹藥加速凝成，但風險極大，火候一失控就會炸爐。
- 火靈能鑽進別人的丹爐，暗中吞火、加火，甚至帶走一顆丹。

## 縮短時間
高階丹藥一爐可能要煉好幾年。能縮短時間的手段因此極為珍貴：
- **催熟靈藥**：把靈藥年份一口氣拉高，省下數百年的等待（見 [[修仙資源]]）。
- **時間加速**：在時間流速不同的空間或領域裡煉丹。

## 丹師分級與法則丹
丹師是修仙世界的高收入生活職業。丹師的等級決定能煉哪些丹，也決定在宗門與坊市的地位。

常見的三層分級：

| 等級 | 能煉的丹 | 稀有度 |
| --- | --- | --- |
| 低階丹師 | 一般修士用的丹 | 常見 |
| 中階丹師 | 高階修士、仙人用的丹 | 千中選一 |
| 頂級丹師 | **法則丹**：蘊含天地法則、能幫人感悟法則的丹 | 十萬中選一 |

- 法則丹表面會浮現**丹紋**，紋路越多品階越高，最高九紋，幾乎只存在於傳說。
- 吃下法則丹也只是**有機會**悟出法則，不保證成功，但對以後參悟大有幫助。
- 法則丹的丹方幾乎都掌握在大勢力手裡，頂級丹師也大多依附大勢力。
- 傳說同一張法則丹方只能被固定人數領悟，額滿之後別人就學不會了，所以持方者更不肯外傳。

## 遊戲化點子
- **丹方收集**：丹方是可收集的配方卡，殘方要補完。
- **配方實驗**：玩家可以嘗試替代材料，發現改良方。
- **煉丹小遊戲**：控制火候與投藥時機，影響成丹率與品質。
- **丹毒機制**：吃丹有邊際遞減與副作用，逼玩家做取捨。
- **丹方 = 交易籌碼**：用丹方換資源、換人情、換名額。
- **火靈煉丹夥伴**：召出火靈當丹火，火靈等級決定可煉丹藥上限；玩家在旁專心做投藥、法訣的小遊戲。火靈同時能戰鬥（見 [[靈寵]]）。
- **猛火賭博**：可選擇讓火靈爆發，縮短煉丹時間、提高品質，但失敗就炸爐，材料全毀。
- **丹紋 = 品質標記**：成丹時顯示丹紋數，高紋丹可拍賣、可上貢、可換勢力名額。
- **名額制丹方**：伺服器內同一張稀有丹方只開放前 N 名玩家領悟，形成搶先與壟斷。
- **古爐奪丹**：秘境裡的古丹爐會自動出丹並引來丹劫，眾人搶丹；派火靈潛入爐中能加速出丹，還能偷藏一顆。
