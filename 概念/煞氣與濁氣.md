# 煞氣與濁氣

靈氣是修士的養分，煞氣是它的反面：殺戮、怨念、死亡累積出來的污濁之氣。它既是威脅，也是魔修、鬼修的資源。清濁分層的宇宙觀見 [[宇宙層級]]。

## 公共來源
- **煞**：道教與風水都用「煞」指凶惡、傷人之氣，如「犯煞」「煞氣重」。
- **天罡地煞**：道教有三十六天罡、七十二地煞的星神信仰，天罡屬陽、地煞屬陰，常被借來做功法或神通的名目。
- **清濁**：清氣上升、濁氣下沉，可以一次解釋靈氣與煞氣的分布。

## 煞氣從哪裡來

| 來源 | 說明 |
| --- | --- |
| 殺戮 | 殺人越多，身上的煞氣越重 |
| 怨念 | 冤死者的怨氣積聚不散 |
| 古戰場、亂葬崗 | 大量死亡留下的煞地 |
| 陰脈、地底 | 天生陰濁的地方 |
| 修煉魔功 | 修煉本身就會沾染煞氣 |

## 煞氣的影響
- **侵蝕心智**：煞氣入體會放大殺意與心魔，見 [[天劫與心魔]]。
- **污染靈力**：法力變得駁雜，影響突破。
- **招來天罰**：煞氣過重的人渡劫更難。
- **被感知**：煞氣是很明顯的氣息，正道修士一眼就看得出，見 [[隱匿與追蹤]]。

## 怎麼處理煞氣
- **壓制**：服用丹藥暫時壓住，見 [[煉丹與丹方]]。
- **淨化**：佛門願力、陽屬性的雷火、特定靈泉能化去煞氣。
- **封存**：把煞氣封進法寶、陣法裡，變成可用的力量。
- **轉化**：魔修、鬼修把煞氣當作靈氣修煉，見 [[功法與煉體]]。
- **隔離**：把煞氣導到特定區域或另一個界面，慢慢淨化。

## 遊戲化點子
- **煞氣值**：殺怪、殺人會累積煞氣，提高傷害但降低理智或渡劫成功率。
- **煞地地圖**：古戰場、亂葬崗是高風險高收益的區域，正道玩家要防護，魔道玩家反而如魚得水。
- **陽剋陰**：雷、火、佛光對煞氣、陰物有額外傷害，做成屬性克制。
- **淨化任務**：替被煞氣污染的地方或人淨化，是正道的聲望來源。
- **煞器**：用煞氣煉的武器威力大，但會慢慢侵蝕持有者。
