# 從屬與手下

修為越高，身邊的人越多：弟子、僕從、侍女、侍妾、靈寵、傀儡。誰跟著你、為什麼跟、會不會背叛，是修仙世界人際與勢力經營的核心。

## 從屬的種類（類型慣例）

| 類型 | 關係 | 忠誠來源 |
| --- | --- | --- |
| 弟子 | 師徒傳承 | 師恩、資源 |
| 僕從、侍從 | 雇傭或投靠 | 庇護、報酬 |
| 侍女 | 照顧起居的隨從 | 庇護、報酬 |
| 侍妾 | 有名分的伴侶，地位低於道侶 | 依附、名分 |
| 靈寵、靈獸 | 契約夥伴 | 契約、餵養 |
| 傀儡 | 煉製出來的戰鬥或勞動單位 | 神識操控 |
| 附庸勢力 | 依附的小家族、小宗門 | 利益交換 |

## 控制與保證忠誠的手段
完整的分類（含蟲蠱、封印修為）見 [[控制手段]]。

- **心魔之誓**：以心魔為誓，違背就會在突破時遭反噬。
- **血契**：以精血訂下的契約，常用於靈獸與交易保證。
- **禁制、神魂印記**：在對方神魂中下禁制，可以控制生死。
- **魂牌**：以一縷分魂和精血煉製，本人身死魂牌就碎，宗門用來確認弟子生死（見 [[分魂與化身]]）。
- **利益與恩情**：最穩定也最容易變的方式。

## 設計注意
- 「侍妾」在類型作品中常與把人當作修煉資源（「爐鼎」）的設定一起出現，涉及剝削與強迫。遊戲若採用，建議只保留「隨從、伴侶」的人際意義，或明確把剝削行為放在反派身上。
- 強制控制（神魂禁制、奴契）適合做成反派手段或道德抉擇，而不是正面推薦的玩法。

## 遊戲化點子
- **隨從系統**：招募、培養、派遣手下去採藥、打探、看守洞府。
- **忠誠度**：手下有忠誠值，資源分配與事件選擇會影響它，低到一定程度就會背叛。
- **契約選擇**：用恩情、利益或強制手段招募，各有代價與後果。
- **傀儡軍團**：神識決定能操控的傀儡數量，見 [[神識]]。
