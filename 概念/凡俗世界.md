# 凡俗世界

修仙世界的地基是凡人。絕大多數人沒有靈根，一輩子種田、做官、打仗，而修士活在他們頭頂上。這層關係決定了修士的來源、資源與倫理。宇宙結構見 [[宇宙層級]]，修士勢力見 [[勢力類型]]。

## 仙凡之隔
- **壽命差距**：修士閉關一次，凡人親友就老死了，見 [[壽元與天人五衰]]。
- **力量差距**：一個低階修士就能左右一場戰爭。
- **認知差距**：凡人眼中的修士是神仙、妖人或傳說。
- **身分轉換**：凡人測出靈根就被帶走，從此和家族漸行漸遠，見 [[靈根與資質]]。

## 修士和凡俗的關係

| 模式 | 說明 |
| --- | --- |
| 不涉凡俗 | 修士之間約定不得干涉凡間，或因果業力太重，修士自己避開 |
| 宗門扶持王朝 | 王朝背後有宗門撐腰，王朝供奉資源與弟子，宗門保它不亡 |
| 國師、供奉 | 修士在朝廷掛名，享俸祿、保國運 |
| 修士治國 | 國家由修士直接統治，凡人只是勞力與人口 |
| 凡人是資源 | 魔道把凡人當血食、煉魂材料，正道則以此為敵 |

中國古代朝廷設有管理道教的官職（如明代的道錄司），國師也真實存在，這些都能拿來包裝「朝廷管修士」的設定。

## 世俗武林
- 凡人中的武者練內功、走江湖，是修仙世界的最底層。
- 頂尖武者也打不過低階修士，但可能成為修士的護衛、眼線或手下，見 [[從屬與手下]]。
- 「武者踏入修仙」是常見的開局。

## 用修為衡量國家
國家或地區的地位可以由「最強修士是什麼境界」決定：有沒有出過某個境界的高手，直接決定它在修士世界裡的等級。這個點子很好用，但分級的名稱與標準要自己設計（見 [[避免照搬清單]]）。

## 資源池與衝突
一個封閉的世界裡，靈脈、靈石、天材地寶的總量有限，能養活的高階修士也有限。一人上去，就要有人下來。用這個解釋正魔之爭、宗門戰爭，比單純的「正邪之分」更有層次，見 [[陣營與動機]]。

## 遊戲化點子
- **凡人開局**：從世俗村落或武林起步，測靈根是第一個轉折。
- **凡間關係線**：家人、故鄉隨時間老去，回鄉時物是人非，是強力的情感事件。
- **國運系統**：玩家扶持一個凡人王朝，王朝提供資源、弟子與香火。
- **因果值**：干涉凡俗累積因果，影響渡劫難度，見 [[天劫與心魔]]。
- **國家等級**：地區由最高修為決定地位，玩家突破能提升家鄉的地位。
