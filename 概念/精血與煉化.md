# 精血與煉化

兩個貫穿整個修仙系統的機制：**精血**是修士身上最珍貴的血，帶有本人的生機與神魂印記，可以拿來控制、綁定、追蹤，也能燃燒換取力量；**煉化**則是把外物吸收、轉為己用的過程，法寶、丹藥、妖丹、異火、血脈都要煉化才算真正屬於自己。

## 精血

精血不是普通的血，而是凝聚修士本源的那幾滴。用掉會傷元氣，大量損耗要閉關數年才能補回，所以每一次使用都是取捨。

| 用途 | 說明 |
| --- | --- |
| 控制 | 以精血種下禁制，控制靈寵或他人；控制力通常有範圍、有上限 |
| 認主、祭煉 | 把精血煉進法寶，讓法寶與自己心神相通 |
| 契約 | 血契：以精血立約，違約有代價 |
| 追蹤 | 憑一滴精血感應本人方位；距離越遠、跨越界面就越難 |
| 生死感應 | 魂牌、魂燈以精血加分魂煉成，人死即碎（見 [[分魂與化身]]） |
| 封印 | 以精血封門、封印，強度遠高於普通禁制 |
| 燃燒換力量 | 血遁、加持寶物、發動號令，事後元氣大傷 |
| 替身 | 以精血造出假身誘敵 |
| 血脈 | 真靈精血可以融合、覺醒血脈，也常是開啟特定秘境的鑰匙 |

**風險**：精血落入他人手中，等於被人掌握追蹤與詛咒的媒介，所以修士會小心不讓精血外流。

## 精血被人控制

換個角度看：當自己的精血落在別人手裡，就成了被控制的一方。這是修仙世界裡「人身不自由」最常見的形式。

**精血怎麼落到別人手上**
- 戰敗被擒，被逼交出精血或被強行抽取。
- 交易、結盟時作為抵押，保證不背叛。
- 加入宗門、城市時登記：魂牌、身分指環都要滴入精血。
- 受傷時留下的血跡被人收集。
- 從小被種下禁制，例如被收養的弟子或靈寵。

**被控制的後果**
- 行蹤被追蹤，走到哪都能被找到。
- 行動受限，被迫執行簡單指令。
- 生死操於人手，對方一念就能引爆禁制。
- 被詛咒、被施加遠距離傷害。
- 被迫效命，成為手下或死士（見 [[從屬與手下]]）。

**控制的限制**
- **修為差距**：雙方修為接近時，控制力很弱，可能只能操控簡單動作，驅動不了對方法力。
- **範圍**：常有距離限制，例如百里之內有效。
- **媒介**：控制常綁在令牌、魂牌等器物上，媒介毀了，控制就斷。
- **意志**：神識強大或心志堅定的人，可能抗拒或延遲命令。

**脫身的方式**
- 摧毀控制媒介。
- 修為超越控制者，禁制自然失效。
- 奪回或銷毀自己的精血。
- 請高人以秘術解禁，通常要付出代價。
- 控制者死亡：可能就此自由，也可能觸發同歸於盡的禁制。
- 以替身、秘術轉移禁制，或乾脆捨棄肉身。

**遊戲化點子**
- **被控制狀態**：玩家某段劇情被他人以精血控制，行動受限，要完成解禁任務才能自由。
- **反制任務**：找出並摧毀控制媒介，或修煉到足以掙脫。
- **精血抵押**：結盟或借資源時要交出精血，背叛的代價很具體。
- **招降敵人**：取得敵人精血後可以收為手下，但對方的忠誠度很低，隨時等待反撲的機會。

## 煉化

煉化是把外物「變成自己的」：抹掉前主的印記、消化其中的力量、與自身融為一體。

| 煉化對象 | 煉化後的效果 |
| --- | --- |
| 法寶 | 抹除前主印記、認主，收發由心 |
| 丹藥 | 吸收藥力；沒煉化完的藥力會殘留成丹毒（見 [[煉丹與丹方]]） |
| 妖丹、獸核 | 吸收妖獸修為或屬性 |
| 異火、天地靈物 | 納入體內成為神通，常需要極長時間 |
| 靈氣、靈石 | 日常修煉 |
| 血脈、精血 | 改造體質、覺醒能力 |
| 器靈、殘魂 | 收服寄居在法寶中的靈 |

**煉化的規則（類型慣例）**：
- **需要時間**：高階的東西可能要煉化幾年甚至幾百年，常拿「一絲一絲煉化」形容。
- **有進度**：初步煉化能用，完全煉化才能發揮全力。
- **會排斥**：屬性不合、境界不夠、前主印記太強，都可能煉化失敗或反噬。
- **可以加速**：特定輔助材料、靈寵產出、時間加速的空間都能縮短煉化時間。

## 設計注意
類型作品中的「血祭」「煉化活人肉身或元嬰」屬於邪道手段，適合放在反派身上，而不是正面玩法。

## 遊戲化點子
- **精血是第二條命**：使用精血類技能會暫時降低生命上限，要靠閉關或丹藥恢復。
- **精血標記**：取得敵人的精血就能追蹤他、對他下詛咒；反過來，玩家也要防止精血外流。
- **奪寶要煉化**：搶來的法寶要先花時間煉化才能用，煉化度越高威力越大，類似熟練度。
- **煉化進度條**：異火、血脈這類長期目標用煉化進度呈現，輔助材料或靈寵可以加速。
- **煉化失敗**：屬性不合或強行煉化會反噬，增加風險決策。
