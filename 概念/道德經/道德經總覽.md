# 道德經總覽

《道德經》是道家的根本經典，相傳為春秋時老子所著，共約五千字、八十一章。修仙作品裡的「道」「天道」「無為」「天地不仁」「反者道之動」「三生萬物」幾乎都出自這裡。原文是公共領域，可以自由引用。

## 結構
- **道經**：第一章到第三十七章，談「道」本身。
- **德經**：第三十八章到第八十一章，談「德」，也就是道在人與萬物身上的體現。
- 常見版本：王弼注本（通行本）、河上公章句、馬王堆漢墓帛書本（德經在前，又稱《德道經》）。

## 修仙作品最常借用的十個概念

| 概念 | 原文（章） | 一句話意思 |
| --- | --- | --- |
| 道不可言 | 「道可道，非常道。」（一） | 說得出來的道，就不是永恆的道 |
| 道生萬物 | 「道生一，一生二，二生三，三生萬物。」（四十二） | 萬物從道逐層生成 |
| 陰陽調和 | 「萬物負陰而抱陽，沖氣以為和。」（四十二） | 萬物都含陰陽，靠氣調和 |
| 道法自然 | 「人法地，地法天，天法道，道法自然。」（二十五） | 道的最高準則是自然而然 |
| 天地不仁 | 「天地不仁，以萬物為芻狗。」（五） | 天道沒有私情，對萬物一視同仁 |
| 物極必反 | 「反者道之動，弱者道之用。」（四十） | 道的運動是往反面循環 |
| 柔弱勝剛強 | 「天下之至柔，馳騁天下之至堅。」（四十三） | 最柔的能駕馭最硬的 |
| 上善若水 | 「上善若水。水善利萬物而不爭。」（八） | 最高的善像水一樣不爭 |
| 無為 | 「為學日益，為道日損。損之又損，以至於無為。」（四十八） | 求學是加法，修道是減法 |
| 損有餘補不足 | 「天之道，損有餘而補不足。」（七十七） | 天道會削高補低 |

詳細的修仙與遊戲詮釋見 [[道德經與修仙]]。

## 與其他筆記的關係
- 「三生萬物」與[[易經總覽|易經]]的太極、兩儀、四象是同一套生成觀。
- 「萬物負陰而抱陽」是[[五行]]、[[八卦]]陰陽系統的哲學基礎。
- 「天地不仁」「反者道之動」常被用來解釋天道與天劫，見 [[天劫與心魔]]、[[法則與大道]]。
