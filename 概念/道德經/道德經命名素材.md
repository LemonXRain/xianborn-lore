# 道德經命名素材

從《道德經》原文挑出可以直接拿來命名的詞句：境界、功法、神通、法寶、地名、宗門。原文是公共領域，名字可以照用；括號內是章數，方便回查 [[道德經原文]]。

[[道德經與修仙]] 講的是觀念怎麼變成機制，這篇只管「叫什麼名字」，兩篇搭配看。

## 一、四個核心概念的設定用法

### 道：先於天地、說不出名字的本源
> 有物混成，先天地生。……吾不知其名，字之曰道，強為之名，曰大。（二十五）
> 道之為物，惟恍惟惚。惚兮恍兮，其中有象；恍兮惚兮，其中有物。（二十一）

- **設定**：道不是神，是一種「無名」的本源。誰叫得出它的真名，誰就掌握它的一部分；這可以變成「悟道 = 為道命名」的機制。
- **層次**：「恍惚 → 有象 → 有物 → 有精 → 有信」（二十一）是道從無形到可感的五步，可用來描述領悟大道的過程，或法則顯化的階段（見 [[法則與大道]]）。

### 無為：不刻意，反而無所不能
> 道常無為而無不為。（三十七）
> 為學日益，為道日損。損之又損，以至於無為。（四十八）

- **設定**：低階修士靠「加」：靈力、丹藥、法寶；高階修士靠「減」：放下執念、散去多餘的術法，直到不施法也能影響世界。
- **戰鬥表現**：「不出戶，知天下」（四十七）、「善戰者不怒」（六十八），頂級高手可以不動手、不移動，靠領域或氣場取勝。

### 陰陽：萬物都由兩種力調和
> 萬物負陰而抱陽，沖氣以為和。（四十二）
> 知其雄，守其雌……知其白，守其黑……知其榮，守其辱。（二十八）

- **設定**：靈力分陰、陽兩性，「沖氣」是讓兩者調和的第三種力，可做成修士的稀有天賦或第三種靈力。
- **成對概念**：《道德經》喜歡講成對的東西，例如有無、難易、長短、高下（二）；雄雌、白黑、榮辱（二十八）；張歙、強弱、興廢、與奪（三十六）。每一對都可以當成一組相剋的屬性或功法。

### 樸與嬰兒：返本歸元
> 復歸於嬰兒……復歸於無極……復歸於樸。（二十八）
> 含德之厚，比於赤子。（五十五）

- **設定**：修煉的終點不是變強，而是回到最原初的狀態。這可以和元嬰境界接上：「元嬰」不只是丹中生嬰，也是「復歸於嬰兒」的第一步。

## 二、境界命名靈感

原文裡有好幾串天然的「階梯」，可以整串拿來當境界或心法層數。

### 第十六章：歸根復命（最完整的一串）
> 致虛極，守靜篤。萬物並作，吾以觀復。……歸根曰靜，是曰復命。復命曰常，知常曰明。……知常容，容乃公，公乃王，王乃天，天乃道，道乃久，沒身不殆。

| 層次 | 名稱 | 可以表示 |
| --- | --- | --- |
| 1 | 致虛 | 清空雜念，入門 |
| 2 | 守靜 | 能長時間入定 |
| 3 | 觀復 | 看見萬物循環，開始感知法則 |
| 4 | 歸根 | 找到自身道基 |
| 5 | 復命 | 壽元與天地相連 |
| 6 | 知常 | 掌握恆常之理 |
| 7 | 明 | 洞見 |
| 8 | 容 → 公 → 王 → 天 → 道 → 久 | 高階六境，一路從「包容萬物」走到「與道同久」 |

前七層適合當**心法層數**，後六個單字適合當**仙界境界**，字少、有氣勢。

### 第五十四章：修之於身到天下（影響範圍）
> 修之於身，其德乃真；修之於家，其德乃餘；修之於鄉，其德乃長；修之於國，其德乃豐；修之於天下，其德乃普。

身 → 家 → 鄉 → 國 → 天下，五層由小到大，適合做**領域範圍**、**神識覆蓋**或**宗門經營**的等級：真德、餘德、長德、豐德、普德。

### 第三十八章：道德仁義禮（反向的衰落鏈）
> 失道而後德，失德而後仁，失仁而後義，失義而後禮。

道 → 德 → 仁 → 義 → 禮，是**往下掉**的階梯。可以用在：
- **世界史的五個紀元**：從「道紀」一路衰落到「禮紀」，現在的末法時代就是禮紀。
- **仙界的品階**：越接近「道」越高，凡間的修士只能修到「禮」「義」。

### 第四十一章：上士、中士、下士（資質）
> 上士聞道，勤而行之；中士聞道，若存若亡；下士聞道，大笑之。

可以直接當**悟性等級**，與 [[靈根與資質]] 的靈根並列：靈根決定修得多快，士品決定悟得多深。

## 六、宗訓、門規與台詞
可直接放進 NPC 對白、宗門匾額、功法扉頁：
- 「知足不辱，知止不殆。」（四十四）：謹慎型宗門的門規
- 「勝人者有力，自勝者強。」（三十三）：心魔關卡提示
- 「禍兮福之所倚，福兮禍之所伏。」（五十八）：奇遇事件的標語
- 「天地不仁，以萬物為芻狗。」（五）：反派或天道的台詞
- 「大成若缺，大盈若沖。」（四十五）：器靈、高人的評語
- 「信言不美，美言不信。」（八十一）：識破騙局的提示
- 「強梁者不得其死。」（四十二）：魔道的結局預言
