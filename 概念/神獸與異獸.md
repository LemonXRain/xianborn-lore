# 神獸與異獸

《山海經》等古籍中的神獸都是公共的文化遺產，可以直接用來設計靈寵、妖族或 Boss。

## 四象與祥獸
- **四象**：青龍、白虎、朱雀、玄武
- **四靈**：麒麟、鳳凰、龜、龍
- **龍生九子**：囚牛、睚眥、嘲風、蒲牢、狻猊、贔屓、狴犴、負屓、螭吻（版本不一）

## 《山海經》與古籍異獸（舉例）
| 名稱 | 古籍特徵 | 可用方向 |
| --- | --- | --- |
| 白澤 | 通曉萬物、能言 | 智慧型 NPC、圖鑑系統 |
| 鯤鵬 | 魚化為鳥，扶搖而上 | 速度、變身 |
| 九尾狐 | 九尾，祥瑞或妖異 | 幻術、魅惑 |
| 貔貅 | 招財、只進不出 | 財運、吞噬 |
| 饕餮、檮杌、窮奇、渾沌 | 上古四凶 | 反派、Boss |
| 朱厭 | 見則大兵 | 戰爭預兆 |
| 夔 | 一足，聲如雷 | 雷屬性 |
| 畢方 | 一足鳥，見則火災 | 火屬性 |
| 精衛 | 填海 | 執念、悲劇 |
| 獬豸 | 能辨是非 | 審判、規則 |

## 類型常見的設定
- 神獸血脈可以繼承、融合、覺醒。
- 妖獸從幼生期到成熟期有成長階段。
- 妖族能化形成人。
