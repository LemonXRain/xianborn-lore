# 修煉境界

境界是修仙世界的等級制度。下面的名稱大多來自道教內丹術語，或已是仙俠類型共用的慣例，可以直接用，也可以自創。

## 類型常見的下界境界

| 境界 | 字面意涵 | 類型慣例 |
| --- | --- | --- |
| 煉氣 | 吸納天地靈氣 | 入門，常分多層 |
| 築基 | 打好道基 | 壽命延長，正式踏入修仙 |
| 結丹／金丹 | 凝結內丹 | 內丹學核心概念「金丹」 |
| 元嬰 | 丹中孕育元神之嬰 | 肉身毀了元嬰還能逃 |
| 化神／出竅 | 元神化形、離體 | 開始借用天地之力 |
| 煉虛、合體、大乘、渡劫 | 與天地相合、準備飛昇 | 下界頂點 |

## 類型常見的仙界境界
「天仙、金仙、太乙金仙、大羅金仙」來自道教神仙體系與《封神演義》等古典小說，是公共的稱號。最頂端常設「聖人」「道祖」「天尊」之類的稱呼。

## 每個境界常見的內部切分
- 初期、中期、後期、巔峰／大圓滿
- 或用「層」（煉氣一層到十三層）

## 可以自己設計的部分
- 每個境界的**硬指標**：打通穴竅數、靈力量、壽元。數字自己定，不要照抄特定作品。
- 突破條件：資源（丹藥）、關卡（[[天劫與心魔]]）、悟性（[[法則與大道]]）。
- 壽元上限：讓「時間」變成壓力來源。
