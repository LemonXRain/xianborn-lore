# 種族與血脈

修仙世界不只有人。**任何生物都可以是一個種族**：只要能開靈智、修煉、繁衍並把血脈傳下去，狐、蛇、龍、鶴、松樹、頑石、甚至一盞古燈成精，都能自成一族。血脈則把種族和力量綁在一起。神獸見 [[神獸與異獸]]，陣營設計見 [[陣營與動機]]。

## 什麼都能成族
成族的條件可以自己定，常見的是：
- **開靈智**：天地靈氣浸潤久了，生物或器物生出神智。
- **能修煉**：有自己的修煉方式，不一定和人族相同。
- **能延續**：靠繁衍、分株、孕育或點化同類，把族群傳下去。

所以種族是**分層的**，大類底下有無數個族，族底下還能分支脈：

| 層級 | 例子 | 說明 |
| --- | --- | --- |
| 大類 | 人、妖、魔、鬼、靈 | 按來源與修煉方式粗分，方便設計陣營 |
| 族 | 狐族、蛇族、龍族、鶴族、松族、石族 | 每一種生物都能是一族，各有天賦與性格 |
| 支脈 | 九尾狐、白狐；青蛇、騰蛇 | 同族不同血脈，血脈越純地位越高 |

## 大類

| 大類 | 來源 | 修煉特點 | 常見處境 |
| --- | --- | --- | --- |
| 人族 | 凡人有靈根者 | 靠功法、丹藥，學習最快 | 數量多、個體弱，靠宗門與陣法抱團 |
| 妖族 | 走獸、飛禽、魚蟲開靈智 | 修到一定程度能化形，有妖丹 | 被人族獵殺取材，也獵殺人族 |
| 魔族 | 異界或濁氣所生 | 魔氣、肉身強橫 | 常是入侵者，但不必是純粹的壞人 |
| 鬼族、冥族 | 魂魄 | 陰氣、魂體 | 住在冥界或陰地，怕陽氣 |
| 靈族、精怪 | 草木、山石、器物成精 | 天生親近某種屬性 | 稀少，常被當作靈材覬覦 |
| 神獸後裔 | 上古神獸血脈 | 天生神通，成長上限高 | 自視高貴，族內按血脈分層 |

大類只是粗分，邊界可以模糊：草木成精算妖還是靈、龍算妖還是神獸，都由世界觀自己決定。

## 族的天賦從本體來
每一族的能力最好從牠「原本是什麼」推出來，玩家一看就懂：

| 本體 | 族的天賦 | 族的弱點 |
| --- | --- | --- |
| 狐 | 幻術、魅惑、多尾即多命 | 怕被看穿原形 |
| 蛇 | 劇毒、蛻皮重生、纏縛 | 怕寒、要冬眠 |
| 鶴、鷹 | 飛行、遠視、長壽 | 地面纏鬥弱 |
| 龜 | 防禦、長壽、卜算 | 慢 |
| 松、柳等草木 | 紮根地脈、再生、分株 | 不能遠離根，怕火 |
| 山石 | 肉身堅硬、與大地共鳴 | 開智極慢、遲鈍 |
| 器物（燈、劍、鏡） | 帶著原本的用途成精 | 本體被毀就會死，見 [[法寶與兵器]] 的器靈 |

## 化形
- 妖族修到某個境界才能化為人形，化形前不能說人話，或只能傳音。
- 化形不完全時保留角、尾、耳等特徵，可以做成角色外觀的成長。
- 血脈越特殊，化形越晚，但進階後越強，見 [[靈寵]]。

## 血脈的常見規則
- **濃度**：血脈越純，能力越強。混血或稀薄的後裔要靠煉化精血提純。
- **覺醒**：血脈平時沉睡，遇到危機、精血或特定秘境才覺醒。
- **返祖**：血脈提純到極致，重現祖先的形態與神通。
- **血脈壓制**：高階血脈對低階生物有天生威壓，弱者見了會本能地臣服。
- **融合**：煉化多種精血融入自身，代價是血脈衝突、反噬，見 [[精血與煉化]]。
- **血脈即鑰匙**：特定血脈才能開啟祖地或秘境，見 [[秘境]]。
- **血脈遺傳詛咒**：詛咒、奴印隨血脈代代相傳，見 [[控制手段]]。

## 遊戲化點子
- **種族選擇**：開局選大類，再選族，決定初始路線、天賦與天敵陣營。
- **萬物皆可成族**：每種怪物都有對應的族群和聚落，殺得太多會被整族記仇，見 [[陣營與動機]]。
- **點化成族**：玩家可以點化一株靈草、一隻靈寵，讓牠開智並成為新族的始祖，見 [[靈寵]]。
- **血脈槽**：角色有血脈槽，煉化精血填入，提純到一定程度解鎖神通或形態。
- **化形外觀**：妖族角色隨境界逐步化形，外觀是成長的獎勵。
- **血脈威壓**：高血脈角色對低階怪物有威懾效果，低階怪不敢靠近。
- **混血身分**：主角是兩族混血，兩邊都不接受，是現成的劇情衝突。
