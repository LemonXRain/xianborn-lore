# 法寶與兵器

修士手上的東西分兩條線：凡間的**兵器**（刀槍劍戟）和修士煉製的**法寶**。類型作品通常讓兩者合流：兵器的外型、法寶的機制。品階見 [[修仙資源]]，認主與煉化見 [[精血與煉化]]，空間類法寶另見 [[洞天與空間法寶]]。

## 十八般兵器（傳統）
刀、槍、劍、戟、斧、鉞、鉤、叉、鞭、鐧、錘、撾、钂、棍、槊、棒、拐、流星錘。

清單各家說法不一，「十八般」只是個泛稱。做武器系統時可以直接當作職業或武器類別的骨架：

| 類別 | 兵器 | 遊戲定位 |
| --- | --- | --- |
| 短兵 | 刀、劍、鞭、鐧、拐 | 快、單體、連擊 |
| 長兵 | 槍、戟、槊、钂、叉 | 攻擊距離長、突刺、橫掃 |
| 重兵 | 斧、鉞、錘、棍、棒 | 慢、破防、擊退 |
| 奇門 | 鉤、撾、流星錘 | 拉扯、纏繞、控制 |

## 法寶按功能分

| 功能 | 常見外型 | 作用 |
| --- | --- | --- |
| 攻擊 | 飛劍、刀、印、鞭、錘、針 | 遠距離操控傷敵，飛劍最常見 |
| 防禦 | 盾、鐘、鼎、寶衣、玉佩 | 護罩、抵擋、反震 |
| 束縛 | 繩、索、網、圈 | 捆住對手或法寶 |
| 收取 | 葫蘆、瓶、缽、袋 | 把人、法寶、火焰收進去 |
| 破寶 | 錢、圈、琢 | 專門打落或收走對方的法寶 |
| 偵測 | 鏡、羅盤、燈 | 照出原形、尋寶、指路 |
| 號令與陣法 | 旗、幡、令牌 | 布陣、驅使、召喚，見 [[陣法]]、[[魂牌與令牌]] |
| 移動 | 舟、車、輪、葉、雲 | 飛行與趕路 |

## 古籍裡的名劍
- **歐冶子五劍**（《越絕書》）：湛盧、純鈞、勝邪、魚腸、巨闕。
- **歐冶子與干將合鑄**（《越絕書》）：龍淵（後避唐高祖諱改稱龍泉）、泰阿、工布。
- **干將、莫邪**（《吳越春秋》、《搜神記》）：雌雄一對的劍，傳說莫邪以身投爐才鑄成。適合做「成對武器」或「以身祭器」的劇情。

## 類型作品的法寶慣例
- **御劍**：飛劍以神識操控，見 [[神識]]。可同時操控的數量是實力指標。
- **本命法寶**：與修士性命相連，用精血溫養、會隨主人成長；被毀則主人重傷。
- **器靈**：高階法寶生出靈智，可能忠誠、叛主或另有所圖。
- **成套法寶**：數量湊齊才能發揮全力，常與劍陣結合。
- **煉器**：器師是和丹師、符師、陣師並列的生活職業，流程是選材 → 熔煉 → 塑形 → 刻禁制 → 祭煉。
- **禁制層數**：法寶內刻的禁制層數決定品質，可以逐層提升。
- **法寶自爆**：最後手段，毀掉法寶換一次爆發傷害。
- **殺人奪寶**：法寶要先抹去原主的神識烙印才能用。

## 遊戲化點子
- **十八般兵器當職業骨架**：每類兵器對應一套招式，搭配法寶的功能分類。
- **攻防相剋**：束縛剋移動、破寶剋防禦、偵測剋 [[隱匿與追蹤]]，做成猜拳式的克制關係。
- **本命法寶養成**：一件武器陪到底，靠溫養、重煉、加刻禁制升級，可以參考 [[武器法寶]] 的研究。
- **成套收集**：湊滿一套才解鎖陣法或合體技。
- **器靈好感度**：器靈有個性，好感度影響法寶的發揮。
- **五行屬性**：法寶帶 [[五行]] 屬性，和功法相生加成、相剋減益。
