# 仙人分類

不同類型的仙代表不同的修煉路線，很適合做成遊戲裡的流派或職業。

## 古典分類（《鍾呂傳道集》五仙）
| 類型 | 原意 |
| --- | --- |
| 鬼仙 | 陰神不散，最下等 |
| 人仙 | 延年益壽 |
| 地仙 | 長生住世於人間 |
| 神仙 | 脫胎換骨、神通廣大 |
| 天仙 | 最高，位列仙班 |

## 類型常見的延伸
- **散仙**：沒有仙籍或正統傳承的仙人，自由但弱勢。
- **劍仙**：以劍入道。
- **體修、武修**：專修肉身，以力破法。
- **信仰神**：靠信徒香火成神（民間土地神、城隍的概念）。
- **魔修、鬼修、妖修**：非正統的修煉路線。
