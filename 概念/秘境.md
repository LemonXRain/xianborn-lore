# 秘境

秘境是與外界隔絕、定期或偶然開啟的特殊空間，裡面有稀有資源，也有致命危險。它是修仙作品最常見的「副本」結構。

## 常見類型

| 類型 | 特色 |
| --- | --- |
| 上古遺跡 | 前人留下的洞府或宗門，藏有傳承與法寶 |
| 試煉之地 | 宗門派弟子進去爭奪資源，常有修為上限 |
| 天地秘境 | 天然形成的特殊環境，產出特定靈藥 |
| 洞天之寶內部 | 某件法寶裡的小世界（見 [[洞天與空間法寶]]） |
| 禁地、絕地 | 極度危險，進去的人多半回不來 |

## 秘境的規則（類型慣例）
- **開啟條件**：定期開放（每幾十年一次）、需要鑰匙或令牌、天象觸發。
- **修為限制**：只容某個境界以下的人進入，高手進不去，讓低階角色也有舞台。
- **人數與名額**：宗門分配名額，名額本身就是爭奪對象。
- **時間限制**：開啟一段時間後關閉，沒出來就被困。
- **內部禁制**：陣法、幻境、守護妖獸，層層關卡。
- **人心比妖獸危險**：同伴與他派修士在秘境內互相殺人奪寶，因為外面看不見。

## 秘境的獎勵
天材地寶、功法傳承、法寶、靈獸蛋、前人留下的機緣或遺言。

## 遊戲化點子
- **Roguelike 一局 = 一次秘境**：限時、限人、隨機生成，出來才算數。
- **修為上限的副本**：等級壓制，鼓勵低階角色的特殊 build。
- **PvP 風險**：同場的其他修士（玩家或 NPC）可能隨時反目，見 [[隱匿與追蹤]]。
- **鑰匙與名額經濟**：進秘境的資格本身就是可交易的資源。
