# 五行

金、木、水、火、土。五行是仙俠屬性系統最常用的基礎，相生相剋讓屬性之間有循環克制。

## 相生（甲生乙）
木 → 火 → 土 → 金 → 水 → 木

## 相剋（甲剋乙）
木 → 土 → 水 → 火 → 金 → 木

## 常見延伸屬性
雷、風、冰、光、暗、毒、空間、時間。延伸屬性通常歸類為「異靈根」或「變異屬性」，稀有但強。
