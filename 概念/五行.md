# 五行

金、木、水、火、土。五行是仙俠屬性系統最常用的基礎，相生相剋讓屬性之間有循環克制。

## 相生（甲生乙）
木 → 火 → 土 → 金 → 水 → 木

## 相剋（甲剋乙）
木 → 土 → 水 → 火 → 金 → 木

## 相生的兩面：生與洩
相生不只是「幫忙」，它是能量的流動，有兩個方向可以利用：

| 用法 | 原理 | 例子 |
| --- | --- | --- |
| 生（補強） | 母生子，處在「母」的環境裡，「子」會更強 | 在金氣濃厚的地方，水屬性的力量天然強上幾分 |
| 洩（吸取） | 子會從母身上吸走力量 | 金屬性的生物進入水屬性領域，自身的金性被吸走，因而避開 |

換句話說，對付一個屬性，除了用「剋」它的屬性正面壓制，也可以用它「生」的屬性慢慢吸乾它。風水上強化吉星用「生」、削弱凶星用「洩」，也是同樣的邏輯（見 [[九宮飛星]]）。

**洩的對照**：木洩水、火洩木、土洩火、金洩土、水洩金（前者吸取後者的力量）。

## 常見延伸屬性
雷、風、冰、光、暗、毒、空間、時間。延伸屬性通常歸類為「異靈根」或「變異屬性」，稀有但強。冰與火的特殊互動（冰焰、冰火融合）見 [[異火與冰火]]。

## 遊戲化點子
- **環境屬性**：地圖區域帶有五行屬性，屬性相生的角色在那裡有加成（地利）。
- **生、剋、洩三種互動**：剋是直接傷害加成；生是給友方加成；洩是持續吸取敵方屬性力量，讓敵人削弱或逃離。
- **領域與元素生物**：由純粹元素構成的生物（如金屬性的異獸），遇到會洩它的領域會本能避開，可以用來驅趕或引導怪物。
- **境界壓過屬性**：屬性優勢有上限，境界差距夠大時，地利與相剋都擋不住。
