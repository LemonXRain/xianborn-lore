# 神識

神識是修士的「精神感知力」：不用眼睛就能感知周圍，還能拿來讀取、傳話、攻擊、防禦。它幾乎是所有高階互動的基礎，也是區分修士與凡人的關鍵能力。

## 神識的用途

| 用途 | 說明 | 遊戲對應 |
| --- | --- | --- |
| 感知 | 掃描範圍內的人、物、靈力 | 小地圖、偵查範圍 |
| 讀取 | 讀玉簡、看儲物袋內容 | 閱讀、鑑定 |
| 傳音 | 只讓特定人聽到的對話 | 私訊 |
| 操控 | 同時操縱多件法寶、傀儡 | 多單位操作上限 |
| 煉化認主 | 在法寶上烙下神識印記 | 綁定裝備 |
| 攻擊 | 直接衝擊對方的神魂 | 精神傷害、暈眩 |
| 防禦 | 抵抗神識攻擊、幻術 | 精神抗性 |

## 類型常見的規則
- **範圍隨境界成長**：境界越高，神識範圍越大、越精細。
- **強弱可比較**：兩人神識碰撞時，強者能壓制或看穿弱者。
- **神識可以被遮蔽**：禁制、洞天、特殊材料能隔絕神識，見 [[洞天與空間法寶]]。
- **掃描會被察覺**：用神識掃描高手，對方會感覺到，可能被視為挑釁。
- **神魂受傷**：神識被重創會頭痛、昏迷、修為受損，是很重的傷。
- **元神**：高階後神識凝聚成元神，肉身毀了元神還能逃，甚至奪舍。

## 遊戲化點子
- **神識範圍 = 視野**：境界越高，地圖上看得越遠；被斂息的敵人不會出現在範圍內。
- **神識值 = 法力以外的第二資源**：操控法寶、讀取物品、施展精神攻擊都消耗神識。
- **掃描的代價**：主動掃描會讓附近的高手發現你。
- **多法寶操控上限**：神識決定同時能控制幾件法寶或傀儡。
