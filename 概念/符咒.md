# 符咒

符咒是「把法術存起來」的道具：事先畫好或念好，需要時立刻發動。在修仙遊戲裡，它通常是消耗品、生活職業（符師）和戰鬥技能三者的交會點。下面的素材來自公共的道教傳統。

## 符籙的結構（道教傳統）

| 部位 | 位置 | 意義 |
| --- | --- | --- |
| 符頭 | 最上方 | 請神、表明來源，常見「敕令」或三清的符號 |
| 符膽 | 中間 | 主神或法力核心，決定這張符的用途 |
| 符腳 | 最下方 | 收尾與鎮壓，常以罡字或特定筆畫結束 |

咒語常以「急急如律令」收尾。這原是漢代公文用語，意思是「依照法令，即刻執行」，後來被道教借用為咒語結尾。

## 畫符的要素
- **材料**：符紙（黃紙）、硃砂、墨，類型作品常加上妖獸血、靈墨。
- **工具**：符筆。
- **時辰與禁忌**：選吉時、淨身、一筆畫完不可中斷。
- **手印（指訣）與咒語**：發動時搭配。

## 常見用途分類

| 類型 | 作用 |
| --- | --- |
| 鎮宅、鎮邪 | 守護一個地方 |
| 驅邪、收妖 | 對付鬼怪 |
| 護身 | 防禦、避災 |
| 治病、安神 | 回復類 |
| 攻擊（雷符等） | 召雷、放火，類型作品最常見 |
| 召請 | 請神將助戰 |

## 雷法與神將
- **雷法**：道教以雷部神祇與雷法為重要法術，「五雷」是常見名目，常用在攻擊符。
- **六丁六甲**：陰神六丁（丁卯、丁巳、丁未、丁酉、丁亥、丁丑）與陽神六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅），是常被召請的護法神將，很適合做召喚系的符。

## 類型作品的符咒慣例
- 符分品級，高階符需要高階材料與修為。
- **一次性**：用了就沒了，是重要的消耗品經濟。
- **符寶**：高手把法寶的一擊封進符中，低階修士也能用一次。
- 符師是常見的生活職業，和丹師、器師、陣師並列。

## 遊戲化點子
- **畫符小遊戲**：照筆順在螢幕上畫符，中斷或畫錯就失敗。
- **組裝符**：符頭（來源）+ 符膽（效果）+ 符腳（範圍或持續時間）三段拼裝，自由組合出不同的符。
- **符 × 八卦**：符膽放入[[八卦]]，決定屬性與方位。
- **符 × 陣法**：在[[陣法]]的陣旗上貼符，改變該格效果。
- **時辰加成**：特定時辰畫的符品質更高。
