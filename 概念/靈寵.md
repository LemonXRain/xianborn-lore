# 靈寵

靈寵是修士收服、培育的靈獸、靈蟲或靈體。它不只是戰鬥夥伴，也是探路、尋寶、剋制特定敵人的工具，甚至能成長到比主人更強。凡人流作品特別愛寫「從一窩小蟲養成大軍」的養成過程。

## 靈寵的種類（類型慣例）

| 類型 | 例子方向 | 特色 |
| --- | --- | --- |
| 靈獸 | 狐、狼、猿、虎 | 單體強，可能化形成人 |
| 靈禽 | 鵬、鶴、鷹 | 速度快，常當坐騎或偵查 |
| 靈蟲 | 蜂、蛛、蠱、甲蟲 | 數量多，可繁殖成群 |
| 鬼物、靈體 | 陰魂、鬼將 | 剋制或驅使鬼物 |
| 器靈 | 寄居在法寶中的靈 | 強化法寶，可能有前世 |
| 傀儡 | 煉製的戰鬥體 | 不需餵養，需要材料與神識操控 |
| 神獸血脈 | 真靈後裔 | 成長上限極高，見 [[神獸與異獸]] |

## 取得方式
- **捕捉**：打到虛弱後收服。
- **孵化**：取得蟲卵、獸卵，從幼體養起，最容易認主。
- **救助**：救下受傷的靈獸，靠恩情結緣。
- **繼承**：前人遺留的靈寵、器靈。
- **交易**：坊市、拍賣會購買（見 [[拍賣會與交易]]）。

## 控制與認主
- **靈獸袋、靈獸環**：收納活物的空間法寶（見 [[洞天與空間法寶]]）。
- **契約**：血契、神識印記，讓靈寵聽命，有些能感應彼此生死。
- **靈智越高越難控**：開了靈智的靈寵有自己的想法，可能討價還價甚至背叛。

## 成長方式

| 方式 | 說明 |
| --- | --- |
| 餵養 | 靈藥、妖丹、專用丹藥；數量越多的蟲群，每隻分到越少 |
| 吞噬進化 | 吞噬同類或特殊材料後升階 |
| 繁殖育種 | 一代代繁衍，後代可能比上一代更強 |
| 外觀變化 | 升階時顏色、花紋改變，例如外殼從銀轉金 |
| 化形 | 修為夠高後化為人形 |
| 血脈覺醒 | 喚醒祖先血脈、前世記憶 |

## 排行榜與圖鑑
類型作品常有某種「奇蟲榜」「靈獸榜」：把天下奇蟲異獸排出名次，附上習性與剋制關係。排名本身就是收集的動機，也是判斷強弱的世界觀工具。

## 靈寵的用途
戰鬥、探路、偵查、尋寶、坐騎、守護洞府、剋制特定敵人（例如專吃鬼物的靈獸）、當法寶的器靈。

## 遊戲化點子
- **蟲群養殖**：一窩蟲可以繁殖、吞噬、升階，數量與品質之間要取捨，搭配加速成長的道具就成了核心循環。
- **奇蟲圖鑑**：有排名的收集圖鑑，排名越前越稀有，附剋制關係。
- **剋制型靈寵**：特定靈寵剋特定敵人，例如吞鬼、破陣、吃金屬，讓組隊有策略性。
- **器靈融合**：把靈寵當器靈放進法寶，法寶升級但靈寵暫時不能出戰。
- **靈寵覺醒**：後期靈寵覺醒前世或血脈，變成劇情角色。
