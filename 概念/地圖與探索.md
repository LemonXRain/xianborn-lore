# 地圖與探索

修仙世界很大、很危險，資訊就是生存資源。「蒐集地圖」讓探索變成一條可經營的成長線：先有地圖，才知道哪裡有秘境、哪裡有傳送陣、哪裡不能去。

## 地圖的種類（類型慣例）

| 類型 | 內容 | 取得方式 |
| --- | --- | --- |
| 一般地圖 | 國家、城市、宗門分布 | 坊市購買、宗門發放 |
| 詳細地形圖 | 山脈、妖獸區、靈脈 | 向當地人打聽、自己繪製 |
| 殘圖 | 只剩一部分的古地圖 | 秘境、遺物，需要拼湊 |
| 藏寶圖、洞府圖 | 前人洞府或寶物位置 | 拍賣、奇遇、殺人奪寶 |
| 傳送陣圖 | 古傳送陣的位置與連線 | 古籍、遺跡 |
| 界面圖 | 跨大陸、跨界的路線 | 高階勢力的秘藏 |

## 常見設定
- **地圖會騙人**：年代久遠、刻意誤導、被人動過手腳。
- **殘圖要湊齊**：幾份殘圖分散在不同人手上，湊齊才能找到秘境。
- **法寶顯圖**：用特殊鏡子或玉簡投影出地圖。
- **打聽也是地圖**：向凡人、散修、商人打聽，自己整理出路線。
- **地圖是情報**：持有某張圖就會被人盯上。

## 遊戲化點子
- **地圖碎片收集**：殘圖拼成完整地圖，解鎖新區域或秘境。
- **戰爭迷霧**：沒有地圖的區域是黑的；買地圖、打聽、探索三種方式揭開。
- **假地圖風險**：地圖有可信度，買到假圖會走進陷阱。
- **傳送網**：收集傳送陣圖，解鎖快速移動。
