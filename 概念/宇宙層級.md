# 宇宙層級

仙俠世界最常見的骨架是「往上飛昇」的多層界面：越往上靈氣越濃、境界上限越高，下界修到頂就要渡劫飛昇。

## 常見層級

| 層級 | 常見名稱 | 角色 |
| --- | --- | --- |
| 下界 | 人間、凡界、下界 | 起點，靈氣稀薄，有境界上限 |
| 中界 | 靈界、上界 | 多數類型作品會加一層過渡 |
| 上界 | 仙界、天界、上清 | 仙人居所，常有天庭統治 |
| 平行異界 | 魔界、妖界、冥界、幽冥、九幽 | 敵對或中立的勢力來源 |
| 原始區域 | 蠻荒、洪荒、混沌 | 資源豐富但危險，古老種族盤據 |

## 公共來源
- **三界**：道教的欲界、色界、無色界，或民間的天、地、人三界。
- **六道輪迴**：佛教的天、人、阿修羅、畜生、餓鬼、地獄，常用來設計冥界和轉世。
- **洪荒**：上古神話的混沌初開時期。

## 清濁分層：一種公共的宇宙生成說
古代宇宙論常說，混沌之中「清輕者上為天，濁重者下為地」（《列子·天瑞》一類說法）。這可以直接拿來做世界觀的物理基礎：

- 越清的氣越往上、越純，形成高階界面；越濁越往下，形成低階界面。
- 修士體內的氣夠清，就會「浮」到上一層，這就是飛昇。
- 世間的殺戮與怨氣淤積成「煞氣」，需要某個地方去容納淨化，可以是一個專門的異界。
- 死後的神魂需要回收、洗去記憶，可以是冥界或幽冥的功能。

這樣一套「氣的循環」就能同時解釋界面層級、飛昇、異界存在的理由。粉絲對《凡人修仙傳》的類似推論見 [[凡人修仙傳前傳（影片解析）]]。
