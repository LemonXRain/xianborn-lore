# 功法與煉體

功法是修士「怎麼修」的說明書：決定吸收哪種靈氣、往哪條路走、能修到多高。境界見 [[修煉境界]]，靈根見 [[靈根與資質]]，修士類型見 [[仙人分類]]。

## 修煉路線

| 路線 | 修什麼 | 長處 | 短處 |
| --- | --- | --- | --- |
| 法修 | 靈力、法術 | 遠程、範圍、變化多 | 肉身脆，被近身就危險 |
| 體修（煉體） | 肉身、氣血 | 硬、耐打、不怕法力被封 | 進度慢、吃資源、缺遠程 |
| 神修 | 神識、神魂 | 神識攻擊、操控、感知 | 肉身與法力都弱，見 [[神識]] |
| 劍修 | 一口劍 | 攻擊力最高 | 路窄，只認一種武器 |
| 魔修 | 魔氣、血氣、殺戮 | 進度快 | 代價重，可能喪失神智 |
| 鬼修 | 陰氣、魂魄 | 不怕肉身毀滅 | 怕陽氣、雷火，見 [[煞氣與濁氣]] |
| 佛修 | 願力、金身 | 剋陰邪、防禦強 | 戒律多 |

路線可以並修：法體雙修是常見的主角配置，代價是兩邊資源都要供。

## 功法品級
- **天地玄黃**：借《千字文》開頭四字分四品，每品再分上中下。類型作品最常見的分法之一。
- **數字品級**：一品到九品，哪邊最高自己定。
- **按境界上限分**：這部功法最多能修到哪個境界。修到頂就得換功法，換功法是常見的劇情節點。

## 功法的常見規則
- **屬性對應靈根**：火靈根修火屬性功法事半功倍，屬性不合就修得慢或修不成。
- **主修一部**：主修功法決定根基，通常只能一部；輔修的術法、身法、斂息術可以很多。
- **殘篇**：功法缺了後半部，修到一半就斷路，要四處找下卷。
- **功法衝突**：兩部功法屬性相剋，同時修會反噬，見 [[五行]]。
- **散功重修**：廢掉已有修為改修更好的功法，代價是時間和風險。
- **走火入魔**：運功出錯、心境不穩或強修不合的功法，見 [[天劫與心魔]]。
- **魔功捷徑**：魔功或禁術能讓修為暴漲，代價是神智、壽元或心性。
- **功法即身分**：特定功法的氣息會暴露師承，所以要用斂息術遮掩，見 [[隱匿與追蹤]]。

## 煉體
煉體是不靠靈根的路線，很適合「資質差的主角」或「修為被封住、只能從肉身重新起步」的劇情。

類型常見的分階（名稱自己取）：

| 階段 | 表現 |
| --- | --- |
| 皮 | 刀槍難入，像穿了一層甲 |
| 肉、筋 | 力量與爆發大增 |
| 骨 | 能硬接法寶，骨頭可刻符文 |
| 臟腑、血 | 氣血如爐，傷勢自癒加快 |
| 髓、竅 | 打通體內穴竅，肉身自成一個小天地 |

- **淬體材料**：藥浴、妖獸精血、雷擊、火焰、重力場，都是常見的煉體手段。
- **煉化血脈**：吞服或煉化神獸精血改造肉身，見 [[精血與煉化]]、[[種族與血脈]]。
- **骨上刻法**：把法寶或符文熔進骨骼，肉身就是武器，見 [[法寶與兵器]]。

## 遊戲化點子
- **路線即職業**：法修、體修、神修三條主線，加劍修、魔修等特化分支。
- **功法 = 技能樹**：主修功法決定樹的形狀，輔修術法是可替換的技能欄。
- **殘篇收集**：功法的上中下卷散在不同地圖、勢力、秘境，是長線收集目標。
- **換功法的取捨**：散功重修會掉等級，換來更高的上限。
- **煉體 = 不怕封印的保險**：法力被封、被禁空時，體修照樣能打。
- **魔功誘惑**：給玩家一條快速變強的路，代價是理智值或陣營聲望。
