# 宗門

宗門是修仙世界最基本的組織單位，也是主角起步、爬升、離開又回歸的舞台。它同時提供資源、規矩、靠山與敵人。

## 宗門的層級（類型慣例）

| 層級 | 角色 | 說明 |
| --- | --- | --- |
| 太上長老、老祖 | 宗門最強者 | 平時閉關，是宗門的底牌 |
| 掌門、宗主 | 對外代表、行政領袖 | 修為未必最高 |
| 長老 | 各峰、各堂的負責人 | 有自己的派系與親傳弟子 |
| 親傳弟子 | 長老親自教導 | 資源最多 |
| 內門弟子 | 宗門核心成員 | 通過考核晉升 |
| 外門弟子 | 一般成員 | 做雜務換資源 |
| 記名弟子 | 名義上掛在某長老名下 | 地位曖昧，常是主角起點 |
| 雜役、僕役 | 凡人或低階修士 | 打雜 |

## 宗門的運作
- **貢獻點**：做任務換貢獻，用貢獻換功法、丹藥、洞府、秘境名額。
- **宗門任務**：採藥、巡山、獵妖、護送、剿滅敵對勢力。
- **大比**：定期比武，決定晉升與資源分配。
- **派系鬥爭**：長老之間爭權，弟子被捲入。
- **護山大陣**：宗門的最後防線，見 [[陣法]]。
- **宗門戰爭**：正魔大戰、宗門滅門。

## 宗門與主角的關係弧線（常見）
入門 → 被看輕 → 靠奇遇與努力爬升 → 宗門遭難 → 離開或接手 → 回歸

## 遊戲化點子
- **宗門經營**：玩家從弟子做到長老，最後開宗立派。
- **貢獻經濟**：宗門是玩家穩定的資源來源，但有門規限制。
- **派系選擇**：投靠哪位長老會影響可得資源與敵人。
- **宗門危機**：被滅門或被圍攻的大事件，是章節轉折點。
