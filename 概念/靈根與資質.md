# 靈根與資質

靈根決定一個人能不能修仙、修得多快、適合什麼屬性。這是仙俠角色創建時最常見的「天賦」系統。

## 類型常見的分級
| 類型 | 說明 | 常見定位 |
| --- | --- | --- |
| 天靈根／單靈根 | 只有一種屬性，純度極高 | 天才，修煉最快 |
| 雙靈根 | 兩種屬性 | 優秀 |
| 三靈根 | 三種屬性 | 普通 |
| 四、五靈根（偽靈根、雜靈根） | 屬性雜，修煉慢 | 「廢柴」主角的起點 |
| 異靈根 | 雷、風、冰等變異屬性 | 稀有 |
| 無靈根 | 不能修仙 | 凡人 |

## 其他資質概念
- **體質**：特殊體質天生帶能力或缺陷。
- **悟性**：影響領悟功法、法則的速度。
- **氣運／機緣**：撞上奇遇的機率。

## 「凡人流」的核心張力
主角資質平庸，必須靠謹慎、努力和外力彌補。這是類型裡很受歡迎的敘事結構，本身不屬於任何單一作品。
