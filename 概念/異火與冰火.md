# 異火與冰火

火是修仙世界最常見的力量，也是煉丹、煉器的基礎。到了高階，火不再只是「熱」：有活著的火靈、有冷到極點的「冰焰」、有融合多種火而成的新火。火與冰之間也不只是單純的相剋。

## 火的分級（類型慣例）

| 等級 | 例子 | 特色 |
| --- | --- | --- |
| 凡火 | 柴火、燭火 | 凡人使用，無法煉丹 |
| 地火 | 地底火脈 | 宗門煉丹煉器的常見火源 |
| 靈火、真火 | 修士以法力催生的火 | 可控，能煉丹 |
| 本命之火 | 元嬰、本命法寶所生的火 | 與修士一體 |
| 異火 | 天地間少見的奇火，有的已生靈智 | 威力極強，可收服、可成長 |
| 陰火、冰焰 | 外形是火、本質至陰至寒 | 燒的不是溫度，而是生機與神魂 |

## 火與冰的關係
- **相剋但看強弱**：火冰相遇會交融成霧氣，誰壓過誰取決於品級與修為，不是固定的勝負。
- **冰火交融**：兩種相反的力量融合，可能誕生更強的新火（例如冰屬性的火）。融合有風險，強行融合容易被反噬。
- **屬性的盲區**：以單一屬性法則構成的術法，可能無法處理相反的屬性。例如冰屬性的幻鏡映不出火的影像，火就成了破解的鑰匙。
- **體內防禦**：寒氣入體會凍結生機，可以用火守住要害；反之亦然。

## 冰焰：冷到極點的火
「陰極生陽、陽極生陰」：極寒之物以火的形態存在，看起來是火焰，散發的卻是奇寒。這類火通常專門傷害神魂、元嬰，而不是肉身，是最可怕的異火之一。

## 火靈：活著的火
高階異火可能生出靈智，成為火靈（火鳥、火人等形態）：
- 可以像[[靈寵]]一樣吞噬火材料成長，例如吃下帶有火力的礦石或丹砂。
- 平時當煉丹的丹火，戰時化形出戰，一火多用（見 [[煉丹與丹方]]）。
- 可以分裂、化形、鑽入縫隙，比一般火焰靈活。

## 遊戲化點子
- **火種收集**：異火是可收集的稀有資源，每種火有不同屬性與效果。
- **一火多用**：同一個火靈既是丹爐火源（影響煉丹品質），又是戰鬥夥伴。
- **冰火融合**：把冰焰與其他火融合成新火，失敗會反噬，成功獲得新屬性。
- **屬性盲區解謎**：單屬性的陣法、幻境，用相反屬性破解。
- **神魂傷害**：冰焰類攻擊無視護甲、直接傷神魂，需要特定防禦（見 [[神識]]）。
