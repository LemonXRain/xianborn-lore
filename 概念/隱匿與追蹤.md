# 隱匿與追蹤

修仙世界裡，高手的神識可以掃過一大片範圍，所以「藏」和「找」是一場持續的攻防：隱匿手段對上偵查手段，誰的等級高、誰準備得好，誰就贏。這也是「謹慎型主角」最常用的生存技能。

## 隱匿的四個層次

| 層次 | 藏什麼 | 常見手段 |
| --- | --- | --- |
| 掩蓋身形 | 外觀，讓肉眼看不見 | 隱身術、障眼法、幻術 |
| 遮掩氣息 | 修為與靈力波動 | 斂息術、收斂法力、壓制修為 |
| 偽裝身分 | 讓人認不出是誰 | 易容、改變氣息屬性、冒充 |
| 掩蓋蹤跡 | 移動留下的痕跡 | 抹除痕跡、遁術、傳送、躲入洞天 |

## 追蹤的手段

| 手段 | 原理 |
| --- | --- |
| 神識搜索 | 用神識掃描範圍內的生靈，見 [[神識]] |
| 偵查法術 | 專門看穿隱身或幻術的法眼、瞳術 |
| 追蹤印記 | 事先在對方身上留下印記或標記 |
| 氣息追蹤 | 追蹤對方殘留的氣味、靈力、血氣 |
| 靈獸追蹤 | 嗅覺或感知特殊的靈獸 |
| 推算卜卦 | 用占卜推算方位，見 [[占卜方法]] |

## 攻防的規則（設計原則）
- **一招對一招**：每種隱匿手段都有對應的偵查手段，反之亦然，形成剋制關係。
- **等級差**：高階的偵查看穿低階的隱匿，但準備充分的低階可以騙過高階。
- **代價**：隱匿時通常不能全力出手；一出手就暴露。
- **範圍**：神識有範圍，跑出範圍外就安全。

## 遁術（逃跑手段）
- **五行遁**：土遁、水遁、木遁等，融入對應環境移動。
- **血遁**：燃燒精血換取爆發性速度，事後虛弱。
- **傳送符、挪移陣**：一次性瞬移。
- **遁光**：飛行時的光芒，太顯眼就會被追。

## 遊戲化點子
- **潛行系統**：隱匿值 vs 偵查值，等級與道具決定誰贏。
- **剋制卡組**：隱身↔破隱、斂息↔神識掃描、易容↔看穿真身。
- **追殺事件**：被高手盯上時，靠隱匿、遁術、躲進洞天脫身的逃亡關卡。
- **反追蹤**：先發現對方的追蹤印記並抹除。
