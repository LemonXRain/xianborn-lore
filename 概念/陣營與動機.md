# 陣營與動機

好的反派陣營不是「壞」，而是**有自己的生存問題**。魔族、妖族、異族看起來在侵略、殺戮，但背後有他們不得不這麼做的理由。當玩家理解了動機，敵人就可能變成合作對象；當利益分歧，盟友也可能再度成為敵人。

## 設計原則

| 原則 | 說明 |
| --- | --- |
| 每個陣營都有生存問題 | 環境惡化、天災級威脅、資源枯竭、壽元將盡 |
| 侵略是手段，不是目的 | 打你是為了地盤、資源、退路，不是因為天性邪惡 |
| 內部不是鐵板 | 高層有盤算，一般成員可能毫不知情；派系之間互相算計 |
| 價值觀不同不等於邪惡 | 修煉方式、倫理標準、對「手段」的看法各不相同 |
| 合作建立在利益交集 | 有共同敵人、互補的需求時才合作 |
| 合作需要擔保 | 證據、誓約、抵押、精血或魂牌（見 [[控制手段]]、[[魂牌與令牌]]） |
| 結盟會變 | 目標一變就可能反目，盟友與敵人的身分會流動 |

## 「不同」的幾種來源
- **修煉方式**：靈力與魔氣、吞噬與吐納、肉身與神魂，路線不同，需要的環境與資源也不同。
- **生存環境**：靈氣稀薄、充滿煞氣或魔氣的界面，讓當地種族不得不向外擴張。
- **倫理標準**：有的種族只看結果、不看手段；有的重視血脈與族群勝過個人。
- **壽命與時間感**：長壽種族記得上萬年前的仇恨與恩情，短命種族早已遺忘（見 [[凡人修仙傳前傳（影片解析）]] 中人族與妖族對上古戰功的記憶差異）。

## 共同大敵：讓敵人坐下來談的理由
天災級的威脅（吞噬界面的怪物、天道異變、更上層的壓迫者）會逼不同陣營暫時聯手。這是讓玩家與「反派陣營」合作最自然的劇情裝置。

## 遊戲化點子
- **動機揭露**：陣營的動機要靠探索、潛入、情報逐步揭露；揭露後解鎖新的外交選項。
- **偽裝潛入**：改變氣息、偽裝成敵方種族混入其中，見 [[隱匿與追蹤]]。
- **利益交集任務**：雙方各有所求時，可以交易、互助，但要先驗證對方誠意。
- **陣營內派系**：同一陣營裡有主戰派、主和派、只想自保的派系，玩家可以挑一派合作。
- **流動的聲望**：不設固定的「善惡陣營」，而是各陣營獨立的關係值，事件會讓關係起伏。
- **共同大敵章節**：某個階段所有陣營被迫聯手，之後又回到各自的立場。
- **戰後清算**：共同敵人消失後，盟友的野心浮上檯面，成為下一個衝突。
