# 分魂與化身

高階修士可以把神魂分出一部分，附在另一個身體、物件或另一個時空。這帶來很多好玩的設定：老怪的分魂降臨下界、隨身老爺爺、多分身同時行動、魂牌確認生死、神魂穿越回過去。

## 相關概念

| 概念 | 說明 |
| --- | --- |
| 元神 | 高階修士凝聚的神魂本體，肉身死了元神還能逃 |
| 分魂（分神） | 從元神分出的一縷，可獨立行動 |
| 身外化身 | 另煉一個身體，放入分魂，可同時行動 |
| 奪舍 | 元神強佔他人的身體 |
| 殘魂 | 修士死後殘留的一點神魂，常寄居在法寶裡 |
| 魂牌、魂燈 | 以分魂和精血煉成，本人死了就碎或熄 |

## 「大老分魂」的常見橋段
- **分魂降臨下界**：上界的大能因界面限制無法親自下來，派一縷分魂降臨下界辦事，實力被界面壓制，只剩一部分。
- **留後手**：大能把分魂留在下界或寶物中，當本體渡劫失敗時的備份。
- **隨身老爺爺**：寄居在戒指、玉佩、法寶裡的前輩殘魂或分魂，提供指點，也可能另有圖謀。
- **神魂穿越**：神魂穿越回過去或到別處，附身在當時的人身上，留下因果。
- **分魂被滅**：分魂被殺，本體會受反噬、修為受損。

## 常見規則
- 分魂越多，本體越弱；分出去的部分要收回才能恢復。
- 分魂的實力受載體與界面限制。
- 分魂與本體之間可能有感應，也可能失聯、產生自我意識。
- 奪舍有風險：身體不合、被原主反噬、留下心魔。

## 遊戲化點子
- **多分身操作**：本尊與化身同時在不同地點行動，例如一個閉關、一個探索。
- **老爺爺導師**：寄居法寶的殘魂當教學系統，後期揭露其真實目的。
- **分魂降臨 Boss**：上界大能的分魂降臨，被界面壓制所以打得過，但打贏會被本體記恨。
- **魂牌**：宗門大殿裡的魂牌碎了，觸發劇情事件。
- **穿越附身**：玩家的神魂穿越到過去，附身於某人，改變因果。
- **局外成長的理由**：每次死亡是分魂被滅，本體保留部分記憶，適合 Roguelike。
