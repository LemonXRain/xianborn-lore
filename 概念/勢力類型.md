# 勢力類型

下面是類型共用的勢力原型。具體的勢力名稱、成員和歷史自己創作。

| 原型 | 特色 | 常見衝突 |
| --- | --- | --- |
| 正道宗門 | 名門大派，資源多、規矩多 | 內部派系、門規束縛 |
| 魔道宗門 | 手段狠辣，修煉快但有代價 | 正魔大戰 |
| 修仙世家 | 血緣傳承，看重靈根 | 嫡庶之爭、聯姻 |
| 散修 | 無門無派，自由但資源少 | 生存、被宗門欺壓 |
| 天庭／仙庭 | 上界統治機構，維持秩序 | 壓迫與反抗 |
| 地下組織 | 殺手、情報、黑市 | 交易與背叛 |
| 商會 | 跨地域買賣，消息靈通 | 利益中立 |
| 妖族、異族 | 以種族或血脈為單位 | 種族戰爭 |
| 皇朝 | 凡間政權，與宗門共存 | 修仙者與凡人的關係 |

## 武俠層的勢力（偏凡間）
江湖門派、鏢局、幫會、朝廷、六扇門、武林盟。修仙作品常以江湖小門派作為主角的起點。
