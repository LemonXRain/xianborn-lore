# 遊戲化對照

把通用的修仙概念對應到遊戲系統。

| 修仙概念 | 遊戲系統 | 備註 |
| --- | --- | --- |
| [[修煉境界]] | 等級、經驗條、天賦樹 | 穴竅數、靈力量 = 可量化的進度 |
| 境界突破 | 關卡、Boss 戰 | 搭配 [[天劫與心魔]] |
| [[靈根與資質]] | 開局天賦、屬性骰 | 低資質給獨特補償 |
| [[五行]] | 屬性克制、元素反應 | 相生 = 加成，相剋 = 傷害倍率 |
| [[法則與大道]] | 技能組、牌組、被動 | 領域 = 範圍增益／減益 |
| [[仙人分類]] | 職業、流派 | 法修、體修、劍修、信仰修 |
| [[修仙資源]]的靈草年份 | 品質等級、種田、放置 | 時間就是資源 |
| 丹藥 | 消耗品、合成 | 禁藥 = 有副作用的強化 |
| 法寶 | 裝備、強化 | 品階 = 稀有度 |
| [[神獸與異獸]] | 寵物、召喚、血脈收集 | |
| [[勢力類型]] | 陣營、聲望、任務線 | |
| 壽元 | 時間壓力、回合上限 | 適合 Roguelike |
| 機緣 | 隨機事件 | |

## Roguelike 適配點
- 一局 = 一世修行，壽元耗盡即結束。
- 每次突破 = 一個關卡節點，天劫 = Boss。
- 法則、功法、法寶 = 每局隨機組合的 build。
- 輪迴、轉世 = 局外成長的世界觀理由。
