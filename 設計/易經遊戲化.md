# 易經遊戲化

易經是公共領域，又自帶完整的符號、數字和機率系統，很適合做成修仙遊戲的核心機制。下面是幾個方向。

## 爻 = 最小單位
- 每個爻是一個二元狀態（陰／陽），六爻組成一卦。
- 玩家的「卦盤」有六格，每格放陰或陽，構成當前的卦。
- 改變任一爻就換成另一卦，共 64 種狀態，可以做成 build 或姿態系統。

## 八卦 = 屬性與方位
- [[八卦]]對應[[五行]]，可以直接接上屬性克制。
- 後天八卦的方位，加上[[河圖洛書|洛書九宮]]，可以做成九宮格戰場或陣法盤。

## 六十四卦 = 卡牌／技能
- 每卦是一張卡或一個技能，效果依卦的主旨設計（例如「需」是蓄力等待、「革」是重置變化）。
- 上下卦組合 = 兩張八卦卡合成一張六十四卦卡，適合合成或連攜系統。
- [[八宮卦]]可以當作卡池或陣營分組。

## 變爻 = 回合中的變化
- 起卦得到本卦與之卦：本卦是這回合的效果，之卦是下回合自動轉變的效果。
- 「老陰、老陽」是不穩定狀態，可以設計成會翻轉的高風險效果。

## 占卜 = 隨機事件產生器
- 每次「問卦」用[[占卜方法|蓍草法機率]]產生結果，決定機緣、事件或天劫的形式。
- 比起直接擲骰，起卦的過程本身就有儀式感。

## 和 Roguelike Slot 的接點
- 六個卷軸、每軸只有陰陽兩面 = 一次轉動就是一卦，64 種盤面各有一個效果。
- 變爻 = 特定符號會在下一轉翻面，自然形成連鎖。
