# 《凡人修仙傳》仙界篇配角與敘事節奏

> [!warning] 參考用，不可照搬
> 人物與情節都是忘語作品的專屬內容。自己的遊戲只借用「做法」，見 [[避免照搬清單]]。

這篇接續 [[凡人修仙傳角色塑造與作者邏輯]]：那篇已拆過蟹道人、金童、啼魂、輪迴殿主、古或今，這裡補其他仙界篇配角，並分析全書的敘事節奏。

---

## 一、仙界篇配角（5W＋How）

### 柳樂兒

| 問 | 答 |
| --- | --- |
| Who | 靈寰界雲狐族的少女，族群已沒落 |
| What | 族人被血刀會殺害，失憶中的韓立救了她；之後跟著韓立多年，學到高階的妖修功法，後來被族中長輩接去仙界 |
| When | 仙界篇第一卷〈風起靈寰〉 |
| Where | 靈寰界 |
| Why | 韓立失憶後沒有過去的身分與謹慎的記憶，作者用柳樂兒讓他「重新當一次凡人的保護者」，表現他的本性不只是被經歷壓出來的算計，還有底層的善意 |
| How | 用一個弱小、需要保護的少女，對照失憶前那個步步為營的韓立 |

可借鑑：主角失去記憶或能力時，安排一個依賴他的角色，能看出他「本來是什麼樣的人」。

### 魔光

| 問 | 答 |
| --- | --- |
| Who | 沒有肉身的天外心魔 |
| What | 在靈界與韓立簽下天魔契約，成為受約束的靈寵；在仙界篇為韓立解說仙界常識（例如丹師三階），後來在灰界假扮虛合族，最終以拖住強敵一炷香換回自由，與韓立失去聯繫 |
| When | 靈界篇末簽約，仙界篇前中期活躍 |
| Where | 靈界、仙界、灰界 |
| Why | 「被契約綁住的危險存在」：他知道很多，但隨時想逃。作者用他當**解說員**，又讓解說員本身不可信，資訊就帶著張力 |
| How | 每次提供情報都夾帶私心；最後用一筆交易結束關係，而不是背叛或死亡 |

可借鑑：讓「知道規則的嚮導」本身有自己的目的，玩家得一邊聽一邊懷疑。

### 甘九真（蛟三）

| 問 | 答 |
| --- | --- |
| Who | 無常盟成員代號「蛟三」，輪迴殿的重要人物 |
| What | 和韓立一起離開黑風海域、接護送任務；邀他加入輪迴殿、請他煉丹；在冥寒仙府中，她的輪迴法則與韓立的時間法則產生共鳴 |
| When | 仙界篇第二卷以後 |
| Where | 北寒仙域、冥寒仙府、灰界 |
| Why | 她是韓立與輪迴殿之間的**接點**，也是「時間 × 輪迴」法則共鳴的載體，替後面「輪迴殿主是另一個韓立」的揭露埋線。前傳影片推論中，上一條時間線的韓立道侶名為甘如霜，兩者關係待查證 |
| How | 先以任務夥伴登場，再透過組織邀約與法則共鳴拉近，身分一層層揭開 |

可借鑑：用「代號」介紹一個角色，再慢慢揭露真名與身分，代號本身就是懸念。

### 石穿空

| 問 | 答 |
| --- | --- |
| Who | 魔域之主的第十三皇子，廣源齋的繼承人，修空間法則，能化三頭六臂 |
| What | 和韓立一起探真言門遺跡，被空間漩渦捲入灰界後被韓立救下，兩人一路同行；最後被魔主以法寶拉回仙界 |
| When | 仙界篇第三卷〈時空迷蹤〉 |
| Where | 真言門遺跡、灰界九幽域 |
| Why | 「敵對陣營的皇子成為戰友」：讓魔域不是純粹的敵人。他的父親魔主後來和韓立聯手又反目，石穿空的存在讓這段關係更複雜 |
| How | 用共患難（灰界逃亡、洗煞池）建立友情，最後被父親召回，友情受陣營拉扯 |

可借鑑：和反派陣營的年輕一代交朋友，讓最終的陣營衝突多一層情感成本。

### 小白（墨眼貔貅）

| 問 | 答 |
| --- | --- |
| Who | 蠻荒八大真靈王之一墨眼貔貅的幼獸 |
| What | 認韓立為主，可在原形與人形間切換，後來繼承父親的傳承，與金童一起離開（見既有筆記） |
| When | 仙界篇 |
| Where | 蠻荒界域、花枝洞天 |
| Why | 把靈寵線接上蠻荒政治：牠的血統就是蠻荒的權力 |
| How | 先是小寵物，再揭露血統，最後走向自己的傳承 |

### 精炎火鳥（精炎童子）

| 問 | 答 |
| --- | --- |
| Who | 頭生七色彩焰的銀焰火鳥，化形為精炎小人 |
| What | 潛伏在冥寒仙府丹爐中被韓立收下，平時替韓立煉丹，戰時燒冰破陣（見既有筆記） |
| When | 仙界篇第二卷起 |
| Where | 冥寒仙府、花枝洞天 |
| Why | 一隻火靈同時解決**生產**（煉丹）與**戰鬥**（剋冰），作者還特地寫韓立覺得只拿牠煉丹「有點委屈」，給工具一點人性 |
| How | 先藏身、後現身、再成為日常的生產夥伴 |

可借鑑：靈寵可以有「生產職能」，不只是戰鬥寵。

### 南宮婉與紫靈在仙界篇

靈界篇中，南宮婉在小靈天與韓立團聚；紫靈在魔界再遇韓立（見 [[凡人修仙傳正傳劇情線與地理]]）。兩人在仙界篇的戲份與結局，這次查到的資料沒有交代，待查證。

### 仙界篇配角的共通手法

| 手法 | 例子 |
| --- | --- |
| 用依賴者照出失憶主角的本性 | 柳樂兒 |
| 不可信的解說員 | 魔光 |
| 代號 → 真名 → 身分 | 蛟三（甘九真） |
| 敵方皇子成為戰友 | 石穿空 |
| 血統即政治 | 小白 |
| 有生產職能的夥伴 | 精炎火鳥 |
| 夥伴最終各奔前程 | 金童、小白、魔光、啼魂 |

仙界篇的配角幾乎都「有自己的去處」：恢復前世、繼承傳承、換回自由、回到家族。作者在仙界篇把「配角留在原地」改成「配角主動離開」，因為到了這個層級，每個夥伴都已強到有自己的路。

## 二、敘事節奏

### 1. 卷末都是「離開」

全本原文中，各卷最後一章的章名：

| 卷 | 卷末章名 |
| --- | --- |
| 一 七玄門風雲 | 離開 |
| 二 初踏修仙路 | 返回 |
| 三 魔道入侵 | 傳送 |
| 四 風起海外 | 脫離 |
| 五 名震一方 | 遠行之前 |
| 六 通天靈寶 | 傳送之戰 |
| 七 縱橫人界 | 進入節點 |
| 八 初入靈界 | 靈蟲大成 |
| 九 靈界百族 | 離開雷鳴 |
| 十 魔界之戰 | 驚變 |
| 十一 真仙降世 | 飛昇仙界（大結局） |

Why：忘語的卷是以**地圖**為單位，一卷結束就是主角離開這張地圖。十一卷裡有九卷的卷末章名是移動（離開、返回、傳送、脫離、遠行之前、傳送之戰、進入節點、離開雷鳴，最後是飛昇仙界），證實了「地圖副本式結構」不是讀者的詮釋，而是作者分卷的實際依據。例外的第八、十卷，分別以「靈蟲大成」「驚變」收尾，是以修為成果或劇情轉折斷卷。

### 2. 卷內的循環：準備 → 進入 → 爭奪 → 脫身 → 閉關

每一段大事件幾乎都照這個節奏：

| 階段 | 書中樣子 | 篇幅感 |
| --- | --- | --- |
| 準備 | 打聽情報、買符、布陣、煉丹 | 慢，細節多 |
| 進入 | 秘境開啟、拍賣會、任務出發 | 中 |
| 爭奪 | 多方交手、算計、意外 | 快，高潮 |
| 脫身 | 遁術、傳送、偽裝 | 快 |
| 閉關 | 一句話跳過幾年到幾百年 | 極短 |

Why：**準備寫得慢、閉關寫得快**。讀者看到的是主角如何做決定，而不是如何修煉。閉關就是作者的「時間跳躍按鈕」，讓故事能跨越上萬年而不拖沓。

### 3. 章名短、事件導向

章名多為兩到四字，直接點出本章的事件或物件：〈山邊小村〉〈錦盒之寶〉〈融靈符〉〈雷滅〉〈劍陣重現〉。Why：讀者靠章名就能回想起情節，對超長篇連載的讀者特別友善，也方便日後查找。

### 4. 資訊差製造懸念

- **主角知道、別人不知道**：掌天瓶、第二元嬰、隱藏的修為。讀者跟著韓立「藏牌」，看別人輕敵就有爽感。
- **別人知道、主角不知道**：上古秘密、輪迴殿的布局。讀者跟著韓立一點點拼出真相。
- 兩種資訊差交替使用，前期以前者為主（生存），後期以後者為主（真相）。

### 5. 伏筆的間距

| 伏筆 | 埋下 | 回收 |
| --- | --- | --- |
| 小綠瓶的來歷 | 正傳第一卷 | 靈界篇末收回瓶靈，仙界篇最終章瓶碎 |
| 啼魂的身世 | 正傳亂星海前後 | 仙界篇揭露冥王轉世 |
| 金童的前世 | 正傳培育噬金蟲 | 仙界篇恢復道祖修為 |
| 蟹道人 | 靈界篇末從魔界帶走 | 仙界篇揭露是魔君 |
| 冰魄仙子與虛天鼎 | 人界亂星海 | 靈界篇歸還虛天鼎、助其分魂重生 |
| 向之禮 | 人界大晉化神 | 靈界篇被韓立滅殺 |

Why：伏筆的間距動輒上千章，而且常常**跨界面**回收。人界的人與物會在靈界、仙界再出現，讓讀者覺得整部作品是一個連續的世界，而不是三本書。

### 6. 高潮的配置

- **小高潮**：每個副本的爭奪段，約數十章一次。
- **卷級高潮**：卷末前的大戰或大揭露（例如第三卷越國戰亂與傳送、第十卷天淵大戰）。
- **篇級高潮**：每個界面的最後一卷（人界第七卷、靈界第十一卷）收束該界面的最大秘密。

### 敘事節奏的設計邏輯

- **以地圖分卷**：卷末就是離開。
- **慢準備、快閉關**：篇幅花在決策，不花在修煉。
- **章名即索引**：短而具體。
- **資訊差交替**：前期藏牌，後期解謎。
- **伏筆跨界面回收**：讓三個界面成為同一個世界。

## 三、轉化到本作時可以問的問題

- 本作的「卷」以什麼為單位？卷末是不是主角換地圖？
- 主角在哪裡「慢準備」？哪些時間可以一句話跳過？
- 前期主角藏什麼牌？後期主角要拼出什麼真相？
- 有哪些人或物，能在第一張地圖埋下、在最後一張地圖回收？
- 夥伴最後是留在原地，還是有自己的去處？
