### 秘境的設計邏輯（5W 的 Why）

- **每個秘境都綁一種資源**：血色禁地綁築基丹、虛天殿綁冰焰、廣寒界綁大量靈藥。秘境是資源稀缺的「集中供應點」，所以一定有人搶。
- **進入條件就是劇情門檻**：修為限制、持令、定期開啟，決定了誰能進、誰會遇到誰。廣寒令一令可帶幾人，直接製造拉攏與背叛。
- **秘境兼任歷史碎片**：落日之墓、昆吾山、墜魔谷都在講上古戰爭，見 [[碎片化敘事]]。
- **反覆回訪的「老地方」**：冥河之地去了好幾次，每次修為不同、遇到的人不同，讓讀者有「回到熟悉地點」的感受。

### 2. 常用法術與神通

| 名稱 | 用途 | 設計用意 |
| --- | --- | --- |
| 驅物術 | 控制法器的基礎法術 | 最早的「修士技能」，韓立用它對付墨大夫的遺物 |
| 斂氣術 | 收斂氣息，對抗天眼術 | 謹慎性格的具體化（見既有筆記） |
| 天眼術 | 偵查 | 和斂氣術形成攻防 |
| 羅煙步 | 身法 | 逃命手段 |
| 血影遁 | 燃精血逃命 | 救命但代價重 |
| 失神刺 | 神識攻擊 | 自創的簡化版驚神刺 |
| 夢引術 | 篡改記憶 | 保護凡人也保護自己 |
| 第二元嬰 | 分身 | 主嬰出事時的保命後手 |

### 功法的設計邏輯

- **功法和地圖綁在一起**：每換一張地圖，就換一套主修（人界劍訣、靈界煉體、仙界時間功法）。功法本身就是「這張地圖的規則」。
- **主修＋神識＋保命三條線並行**：韓立很少只修一門。主修決定戰力、神識決定能不能控寶與偵查、遁術與分身決定能不能活。
- **禁術給代價**：煉神術強，但會瘋魔；玄陰訣是魔功，用來做分身。強力手段都有副作用。
- **碎片式功法**：金闕玉書散落、真言門時間功法分五部，收集本身就是主線。

## 三、符籙清單

| 名稱 | 類型 | 取得或用法 | 設計用意 |
| --- | --- | --- | --- |
| 劍符 | 一次性／限次符 | 七玄門死鬥中收走；越用越弱，有次數限制（見 [[武器法寶]]） | 第一次讓主角體會「好東西會用完」 |
| 金光磚符寶 | 符寶 | 用千年靈草換得 | 外掛產出的靈草換戰力 |
| 灰色小劍符寶 | 符寶 | 與同門惡鬥時使用 | 低階打高階的手段 |
| 融靈符 | 輔助符 | 第一百八十三章〈融靈符〉應敵 | 輔助類符籙 |
| 天戈符 | 攻擊符 | 靈界魔劫時自煉，擊殺第一魔尊 | 主角後期自己煉符，從「買符」變成「造符」 |
| 三清雷霄符 | 高階符 | 靈界用寶物換得 | 大乘級的保命符 |

Why：符籙的軌跡是**從買到造**：前期花錢買符、撿符，後期自己煉符。這和韓立從「資源消費者」變成「資源生產者」的成長同步。

## 四、陣法清單

| 名稱 | 類型 | 書中用法 | 設計用意 |
| --- | --- | --- | --- |
| 顛倒五行陣 | 困陣 | 越國戰亂時，韓立讓同伴先去啟動此陣，再把越皇引入陣中 | 「準備＋引敵」的典型打法 |
| 洞府防護與隱匿陣 | 防禦 | 閉關前必布 | 謹慎的日常化 |
| 大庚劍陣（竹劍劍陣） | 劍陣 | 本命竹劍配辟邪神雷布成，第一千一百零七章〈劍陣重現〉 | 本命法寶與陣法結合，成為招牌殺招 |
| 雙重雷陣 | 雷陣 | 與雷雲子聯手，從元剎分身與血光分神的追殺中逃生 | 和他人合作布陣 |
| 傳送陣（上古、跨大陸） | 傳送 | 越國到亂星海、靈界跨大陸 | 換地圖的工具 |
| 護族大陣、上古封印 | 大型陣法 | 人妖兩族的上古大陣、昆吾山封印 | 世界觀層級的陣法，守護與封印 |
| 時間加速大陣 | 時間陣 | 仙界篇閉關十萬年 | 解決「修煉要太久」的敘事問題 |

（各陣法的名稱與章號，除已列章號者外，待查證）

### 符陣的設計邏輯

- **陣法是主角的「第二把武器」**：韓立的戰鬥方式通常是先布陣、再引敵，陣法讓低階打高階變得合理。
- **陣法的層級跟著世界一起長大**：個人洞府陣 → 宗門護山陣 → 種族護族大陣 → 封印界面的上古大陣 → 仙界的時間大陣。
- **陣法兼任劇情工具**：傳送陣換地圖、封印陣藏秘密、時間陣跳時間。

## 五、正傳的天劫與心魔

| 境界 | 劫難 | 書中樣子 | 設計用意 |
| --- | --- | --- | --- |
| 築基、結丹 | 瓶頸（無天劫） | 靠丹藥、靈物提高成功率，失敗會損傷 | 前期的門檻是資源，不是劫 |
| 元嬰 | 心魔 | 結嬰時要過心魔關（細節待查證） | 第一次把「心性」變成門檻 |
| 化神 | 人界靈氣不足 | 人界幾乎不能化神，韓立花五百多年、靠特殊丹藥與寒焰之法才突破 | 「天花板是界面問題」 |
| 飛昇靈界 | 靈界雷劫 | 飛昇者身上有下界印記，在靈界重凝元嬰會引來雷劫；要靠滅塵丹洗去 | 飛昇者要「歸化」 |
| 煉虛以後 | 定期小天劫 | 靈界修士每隔一段時間要渡小天劫（年曆中有「第二次小天劫」） | 長生也有定期的生死關 |
| 合體 | 五行劫、真雷劫、心魔劫 | 見 [[凡人修仙傳]] 境界表 | 劫的種類增加 |
| 大乘 | 飛昇之劫 | 渡劫失敗會隕落（妖族大乘敖嘯渡劫失敗身亡） | 頂層也會死，讓飛昇有分量 |
| 仙界 | 天人五衰、斬三屍、道天大劫 | 見既有筆記 | 劫從「外來的雷」變成「自身的衰敗」 |

### 天劫的設計邏輯

- **劫難隨境界換形態**：前期是資源門檻，中期是心魔，後期是天雷，仙界是五衰。每一階的「敵人」不同。
- **劫是界面規則的一部分**：靈界雷劫專打飛昇者，等於界面在排斥外來者，讓飛昇不只是升級，而是移民。
- **劫會殺死重要角色**：敖嘯渡劫失敗，讓讀者知道主角的劫也是真的危險。

## 六、宗門內部制度

以黃楓谷為主，靈界以天淵城為例。

### 1. 黃楓谷（宗門）

| 問 | 答 |
| --- | --- |
| Who | 元嬰老祖（令狐老祖）、結丹長老（如李化元）、築基弟子、煉氣弟子、雜役 |
| What | 金字塔結構：元嬰老祖是宗門的「核武」，結丹長老收徒、管事，築基弟子是中堅，煉氣弟子做雜務 |
| When | 第二、三卷 |
| Where | 越國黃楓谷 |
| Why | 宗門有幾位元嬰，就決定它在七派中的地位（掩月宗有兩三位，其他多半一位；令狐老祖坐化後黃楓谷就沒有元嬰）。元嬰數量是宗門的國力 |
| How | 見下表 |

| 制度 | 書中樣子 | 設計用意 |
| --- | --- | --- |
| 升仙大會、升仙令 | 七派製作升仙令，賜給立過奇功的修仙家族；持令者不論是誰都能入門並得一枚築基丹 | 門票制：仙途要門路，令牌可以被搶 |
| 記名弟子與正式弟子 | 韓立先是李化元的記名弟子，築基後才成為正式弟子 | 師徒關係看資質與成果 |
| 雜役與藥園 | 資質差的弟子去管藥園 | 外掛的掩護：沒人在意藥園裡的雜役 |
| 試煉名額 | 血色禁地由七派各出弟子 | 宗門用弟子的命換資源 |
| 戰時徵召 | 魔道入侵時弟子要出征 | 宗門的保護有代價 |
| 宗門遷徙 | 戰敗後舉宗遷往他國 | 宗門也會「搬家」，不是永恆的 |

### 2. 落雲宗（掛名長老）

韓立回天南後在天道盟的落雲宗掛名長老（細節待查證）。Why：元嬰修士需要一個名義上的歸屬，宗門也需要元嬰撐場面，雙方是交易關係，不是師徒。

### 3. 天淵城（靈界的軍事制度）

| 制度 | 書中樣子 | 設計用意 |
| --- | --- | --- |
| 衛隊 | 金淵衛、青冥衛等編制 | 飛昇者可以靠服役換資源 |
| 以職換丹 | 韓立當青冥衛換取滅塵丹 | 「為組織工作」換「歸化資格」 |
| 本命牌 | 城中高層靠本命牌確認修士生死；韓立沒留本命之物，他們就無法判斷他的生死（見既有筆記） | 加入組織要交出一部分自由 |

### 宗門制度的設計邏輯

- **元嬰數量是國力**：宗門、國家、種族的強弱都用頂層修士數量衡量，讀者一聽就懂。
- **組織的保護都有價格**：入門要令牌、資源要試煉換、庇護要服役或交出本命牌。
- **主角始終和組織保持距離**：掛名長老、短期服役、不留本命牌，和他「不把命交給組織」的性格一致。
