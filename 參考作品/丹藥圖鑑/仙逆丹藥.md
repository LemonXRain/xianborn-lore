# 《仙逆》丹藥整理

> 來源：耳根《仙逆》全文（繁體轉檔 `仙逆（繁體中文版）.txt`）。範圍：書中有具體名稱的丹藥、原文提到的丹方與材料，以及丹藥品級制度。表格只寫原文有交代的內容，原文沒寫的一律標「原文未詳」。章節名照轉檔原樣抄錄，轉檔偶有錯字（例如「威」應為「成」）。

## 丹藥品級制度

### 一、修真國體系：一～九品，每品再分上、中、下三階

- **基本分法**（第666章）：丹藥分為九品，每品又分上、中、下三階。原文說「九品丹藥便可稱之為神丹」，八品叫「次神丹」，七品叫「仙丹」。
- **這些稱號只是俗稱**：王林認為「仙丹、神丹」只是後人編出來的叫法，跟真正仙、神用的丹藥差距很大，「好似天地」。九品已經是極限，修為一旦踏入「第二步」，這類丹藥就沒有效果了，除非拿到真正的仙丹、神丹。
- **半品**：周林留給王林的玉簡丹方，「全部都是半品靈丹」（第215章）。這是比一品還低的級別。
- **品級的實際例子**：
  - 一品：築基丹（「築基丹是一品靈丹」，第215章）、解障丹（第222章）。
  - 二品上階：岐左丹（第221章）。
  - 三品初階：天離丹（第221章）。
  - 四品：妖血丹（第223章）。
  - 五品初階：天損丹（第211章）。
  - 五品：修魔丹（第214章）。
  - 六品：歸元丹最高到六品（第336章）。
  - 六品上階：王林結嬰時吞下的就是一枚六品上階丹藥（第666章），也就是下面的青雲丹。
  - 八品：次神丹（第666章）。
- **品級跟功效的關係**：
  - 能擴充經脈的丹藥「往往都是四品以上」，二品就有這種效果的很少見（第221章）。
  - 增加壽元的丹藥「最少都是六品靈丹」（第226章）。
- **品級跟修真國等級的關係**（第223章）：
  - 就算是六級修真國，也只能煉出六品靈丹。
  - 個別天才最多煉到「七品下階」。
  - 雲天宗能煉五品丹藥，所以被四級修真國巨魔族庇護。
- **煉丹師也分品**：書中有「五品煉丹師」的說法（第214章）。
- **出爐異象與丹封**（第224章）：
  - 七品靈丹出爐時會有異象。
  - 丹藥可以用「丹封」長期保存。岐黃門原本煉出一枚五品上階靈丹，封存了幾千年，品質有所提升。可惜開封的時機不對，丹表碎裂，品質掉回「偽七品」，實際是六品上階。

### 二、雲海星域體系：以獸魂入藥，分十三階

- 第1143章：雲海星域的靈獸一共分十三階。用靈獸之魂入藥，煉出的丹藥也對應分成十三階。
- 原文出現過的階位例子：
  - 三階丹藥：給陽實境界修士用（第1148章）。
  - 七階、八階離魂丹（第1143、1175章）。
  - 十階極才丹（療傷用）。
  - 十一階丹藥，以及十二階化霧兇獸煉成的霧魂丹（第1198章）。

### 三、仙界丹藥與真正的仙丹

- 用仙界之草製作的仙丹，跟一般丹藥「則大有不同」（第308章）。
- 仙界相關的段落裡另有「四品仙丹」（藏天丹）、「五品凝仙丹」的說法（第1052章）。原文沒有交代這套品級跟上面九品制是什麼關係，這裡只照原文記錄。

## 丹方取得方式的例子

1. **師父傳授**：周林留給王林的玉簡裡記有丹方，全部是半品靈丹（第215章）。
2. **託同門取得**：王林向程賢要築基丹的丹方。程賢說自己沒有，答應去弄，隔天派靈猿送來玉簡（第215章）。
3. **在商舖買**：王林在魔逆城煉器閣用靈石買五品丹方。店家先給一枚只寫功效的玉簡，真正的配方另外放在錦盒裡。王林挑中天涯門的歸原丹（第328章）。
4. **拍賣會**：煉器閣唯一一張六品丹方只在十年一次的修魔拍賣會上賣。王林拿傀儡木雕作價競標，最後被青衣女子買下，她的目的是引王林來見她。王林拓印了一份，另外付給她一枚價值兩萬上品靈石的玉簡當拓印費，丹方就是六品歸元丹（第336～337章）。
5. **翻閱宗門傳承**：王林在歸元宗道觀看了老祖留下的玉簡，學會雲海星域「以獸魂入藥」的煉丹法，但沒有把傳承之物取走（第1143章）。
6. **殺人奪寶與宗派爭奪**：涅空丹的丹方刻在獸骨碎片上，原本由破天宗所得，引發整個雲海星域的浩劫。王林是在骸骨燒成的灰燼中找到它（第1153～1154章）。
7. **宗派的獨門丹方**：岐左丹的丹方是洛河門「九轉十八丹」之一（第221章）；李慕婉在雲天宗看過全部五品丹藥的配方（第328章）。
8. **只剩殘方**：輪迴丹的丹方失傳，只剩半副，「煉不出成丹」（第1182章）。

### 王林自己煉丹或取得丹藥的主要情節

- **凝氣期**：每月領奪靈丹修煉；靠化形化聲丹參加門派私下的交易會（第20～35章）。
- **本尊結丹**：參加火焚國戰爭爭奪天離丹，挾持李慕婉替他祭煉成品，服天離丹結丹（第138～149章）。
- **結嬰前後**：靠萬魔百日誅殺令得到修丹；青衫老者送他立嬰丹（第150～191章）。
- **分身在雲天宗**：跟周林、李慕婉學煉丹，自煉培元丹、築基丹；服岐左丹、解障丹、鎖明丹、天離丹，一路從築基到結丹（第213～222章）。
- **本尊結嬰**：與李慕婉打開岐黃門的丹封，服青雲丹結嬰（第223～224章）。
- **雲海星域**：學會獸魂入藥，煉出三階丹藥、八階離魂丹、魂丹，又取得霧魂丹與十一階丹藥（第1143～1198章）。

## 判斷為非丹藥而排除的名稱

| 名稱 | 排除理由 |
|---|---|
| 結丹、金丹、內丹、假丹 | 境界名稱或體內之物 |
| 寒丹 | 修練《黃泉升竅決》時，在丹田、氣海、祖竅三個穴竅凝結出的東西，三顆融合後有機會直接結丹（第87章）。這是功法產物，不是丹藥 |
| 綠丹 | 四級修真國魔道功法凝結的「綠丹」，跟金丹同類，而且數量沒有限制（第83章）。屬境界或功法 |
| 開啟丹（開啟丹封） | 是「開啟／丹封」，指打開丹藥封存，不是丹名 |
| 斬仙丹 | 是「斬／仙丹」，指王林出手斬斷丹海仙丹 |
| 獸骨丹（獸骨丹方） | 是「獸骨／丹方」，指刻在獸骨上的涅空丹丹方 |
| 海仙丹 | 是「丹海仙丹」被切錯，已併入「丹海仙丹」條目 |
| 元神丹（元神丹田） | 是「元神／丹田」 |
| 青玄丹、百獸丹、七龍丹 | 是「青玄丹爐」、「百獸丹爐」、「七龍丹鼎」，都是丹爐或丹鼎 |
| 元丹（蟾蜍元丹）、藍色圓丹 | 靈獸體內之物，或修士放出的法寶型元丹，不是丹藥 |
| 含朱丹 | 「口如含朱丹」，是形容外貌的修辭 |
| 雞肋丹 | 是「雞肋丹寶」，一種一次性的法寶 |
| 五品貢丹、祭丹 | 「貢丹」疑為轉檔錯字；「祭丹」是歐陽子的煉丹法名稱 |
| 大補丹 | 比喻用法（「一個個大補丹藥一般」） |
