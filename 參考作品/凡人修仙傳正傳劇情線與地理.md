## 三、人界地理

### 1. 四大區域

| 區域 | 位置 | 特色 | 勢力 |
| --- | --- | --- | --- |
| 天南 | 主角起點，數十個國家 | 資源中等，萬年沒有化神 | 越國七派、魔道六宗、正道盟、天道盟、九國盟 |
| 天瀾草原（慕蘭草原） | 與天南相鄰 | 資源匱乏，以靈術和信仰為主 | 慕蘭法士、突兀人（信天瀾獸） |
| 大晉 | 草原另一端，面積約天南十倍 | 人界的修煉聖地，資源最豐、高手最多 | 正魔十大宗門、北冥島小極宮、萬妖谷 |
| 亂星海 | 天南外的海域 | 妖獸的天下，資源以妖獸材料為主，靈藥靈石少 | 星宮（天星城）、逆星盟、外海妖族 |

### 2. 天南的國家與勢力

| 問 | 答 |
| --- | --- |
| Who | 越國、天羅國、風都國、元武國、紫金國、姜國、車騎國、剎雲國、溪國等數十國 |
| What | 天南修仙界分成幾個大陣營：天道盟在北、九國盟在南、魔道六宗在最東（天羅國）、正道盟在西（風都國）；正道盟以西隔著沙漠是大衍神君的千竹教 |
| When | 第一到第三卷、第六卷 |
| Where | 越國是中等國，起點所在 |
| Why | 先給主角一個「小國」：越國七派加起來的元嬰也就幾位，讓讀者感到天南只是更大世界的一角 |
| How | 每個陣營都有自己的成立理由：九國盟為對抗慕蘭法士而結、逆星盟為打破星宮霸權而結。聯盟不是正邪標籤，而是利益的產物 |

越國七派：掩月宗（最強）、靈獸山、黃楓谷、清虛門、化刀塢、天闕堡、巨劍門。
魔道六宗：合歡宗、御靈宗、魔焰門、天煞宗、千幻宗、鬼靈門。
正道盟以太真門等四大派為首；天道盟是十幾國修士的鬆散聯盟，核心有古劍門、落雲宗、百巧院；九國盟以化意門為主。

正魔大戰後的去向：燕家投靠鬼靈門、靈獸山臨陣倒戈歸入御靈宗，其餘六派撤出越國，轉往九國盟一帶（掩月宗、黃楓谷後來在北涼國落腳），元武國被魔焰門佔據。

### 3. 人界的戰力天花板

- 天南萬年沒有化神，元嬰後期就是頂點（除韓立外只有三位）。
- 亂星海的星宮實力約等於大晉一個大宗門，天星雙聖是元嬰後期。
- 大晉的化神有向之禮、呼慶雷、白老鬼、風老怪，以及萬妖谷的車老妖。

Why：作者用**區域落差**取代「境界數值」來表現世界的大小。韓立在天南已是頂尖，到大晉又只是一般高手。每換一個區域，讀者就重新校準一次「強」的定義。

### 4. 人界的上古地點

| 地點 | 是什麼 | 功能 |
| --- | --- | --- |
| 血色禁地 | 越國七派共用的試煉地，產築基丹主藥 | 第一場資源戰 |
| 虛天殿 | 亂星海定期開啟的上古遺跡，藏虛天鼎 | 高階修士的爭奪場，乾藍冰焰在此 |
| 墜魔谷 | 天南的上古絕地，封著上古魔物 | 第六卷的探險副本 |
| 昆吾山 | 上古封印元剎聖祖分神的地方 | 人界最後的大戰場 |
| 北冥島（小極宮） | 大晉西北的冰海島嶼 | 冰鳳與冰海妖族的伏筆 |
| 空間節點 | 人界與靈界之間的裂隙 | 飛昇斷絕後的「偷渡」通道 |

## 四、靈界補完

### 1. 靈界的結構

| 問 | 答 |
| --- | --- |
| Who | 人族、妖族與數百個異族 |
| What | 靈界分成多塊大陸（風元大陸、雷鳴大陸、血靈大陸等）。人族與妖族被劃在同一塊地盤，共處一座上古大陣的保護之下；人妖三境（天元、玄武、天妙）由人族三皇（天元聖皇、玄武霸皇、天妙靈皇）與七妖王分治 |
| When | 第八到第十一卷 |
| Where | 風元大陸，人妖地盤以天淵城為前線 |
| Why | 人族在靈界是**弱小族群**：人妖兩族加起來只有幾位大乘、約兩百位合體。主角飛昇後所屬的族群也一起「變弱」，生存壓力就重來一次 |
| How | 用城池（天淵城、天元城、倚天城）、衛隊（金淵衛、青冥衛）、真靈世家（葉家、隴家、谷家）等制度細節，把人族社會寫成一個邊疆國家 |

### 2. 靈界的主要種族

| 種族 | 特點 | 書中作用 |
| --- | --- | --- |
| 人族、妖族 | 結盟共處，實力偏弱 | 主角的母國 |
| 靈族、木族、影族、器靈族 | 小族，各有一兩位大乘 | 任務與盟友 |
| 天雲十三族 | 十三族聯盟，坐鎮天雲城 | 雷鳴大陸的勢力 |
| 飛靈族 | 七十二支，含天鵬族 | 聖子試煉，韓立得驚蟄十二變 |
| 角蚩族、蜉蝣族、海王族 | 靈界前十的大族 | 高階威脅 |
| 夜叉族 | 好戰異族 | 對手（夜叉王、黑梟王） |
| 五光族 | 異族 | 韓立的仇敵 |
| 長元族 | 青元子奪舍其肉身 | 劇情伏筆 |
| 赫連商盟 | 遍及靈界的商盟（不是種族） | 拍賣與交易 |
| 魔族 | 魔界入侵者 | 魔劫，見 [[陣營與動機]] |

Why：靈界篇的種族不是做成「怪物圖鑑」，而是做成**國際政治**：每個族有大乘數量（等於核武數）、地盤、盟約與恩怨。韓立在各族之間打工、交易、結仇，讀者就自然認識了整張地圖。

### 3. 靈界的關鍵制度與地點

| 項目 | 是什麼 | Why |
| --- | --- | --- |
| 滅塵丹 | 讓飛昇者洗去下界印記、扛住靈界雷劫 | 飛昇者要「歸化」才能在靈界活下去，給主角一個必須投靠人族城池的理由 |
| 天淵城 | 人妖兩族對抗外敵的前線要塞 | 讓主角有組織、有職務、有戰友 |
| 落日之墓 | 上古真靈大戰的遺址 | 真靈血脈的來源 |
| 冥河之地 | 危險禁地，有冥河神乳 | 多次重返的「老地方」，舊識在此重逢 |
| 廣寒界 | 隱藏的空間，持廣寒令可入 | 一次給大量資源的「大機緣副本」 |
| 小靈天 | 隱秘之地 | 與南宮婉團聚的舞台 |
| 魔源海、洗靈池 | 魔界核心 | 魔界之戰的最終目標 |
| 真仙降世 | 仙界真仙馬良降臨，被靈界強者圍殺 | 讓讀者先見識仙界的層級，替飛昇鋪路 |

## 五、設計邏輯小結

- **卷名就是主題**：七玄門風雲、初踏修仙路、魔道入侵、風起海外……每卷名稱都指出這一卷的地圖與核心事件，讀者一看就知道換了副本。
- **每升一界就歸零**：飛昇靈界時連法力都沒了，比單純「境界變低階」更狠。
- **用區域落差校準強弱**：天南的頂點到大晉只是一般，人族到靈界只是小族。
- **勢力是利益的產物**：九國盟、逆星盟、人妖聯盟都有明確的成立理由。
- **時間尺度逐級拉長**：讓「一次閉關錯過一代人」成為常態。
