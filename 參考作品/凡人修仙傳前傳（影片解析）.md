# 《凡人修仙傳》前傳：韓立出生前的世界史（影片解析）

## 一句話
UP 主認為，整部《凡人修仙傳》是一場「天道」對抗「想奪舍天道的人」的棋局：掌天瓶是天道留下的變數，輪迴殿主是上一條時間線的韓立，而我們熟悉的韓立，是瓶靈挑中、被一步步推上場的棋子。

## 核心框架：UP 主的哲學詮釋
- **天道沒有意識**：援引《道德經》「天地不仁，以萬物為芻狗」，天道像法則一樣運轉，沒有私心，所以公平。
- **天道會自我糾偏**：援引「反者道之動」，事物走到極端，天道會自然推它走向反面。
- **遁去的一**：援引《繫辭》「大衍之數五十，其用四十有九」，天道只用四十九，留下的那個「一」是天地間唯一的變數，UP 主把掌天瓶解釋成這個「一」凝成的瓶子（見 [[占卜方法]]）。
- **舞台與演員**：時間、空間、輪迴三大至尊法則是舞台，[[五行]]是在舞台上運行的五種節奏。
- **天人合一的四個層面**：修煉是照著大宇宙在體內造一個小宇宙——軀體（吸收星辰之力、開玄竅）、仙靈力（能量）、神識（神經系統）、真靈之血（生命藍圖）。前兩者是「性」，後兩者是「命」，即道家的性命雙修。
- **反派的共同點**：古或今、魔主、輪迴殿主都想要一個有意識、會回應祈禱的「上帝」，否定天道的變化；瓶靈因此不會選他們當勝利方。

## 宇宙構造（UP 主推論）
天道自行一動生出混沌，清氣上升、濁氣下沉，自然分層成大小「氣泡」：

| 界面 | 形成 | 角色 |
| --- | --- | --- |
| 仙界 | 最清、最核心的氣 | 源頭，力量叫仙靈力 |
| 靈界 | 清濁混合，環繞仙界 | 演化的舞台 |
| 人界 | 最濁、最外圍的小氣泡 | 演化的舞台，力量叫靈力 |
| 灰界 | 殺戮與怨氣產生的「煞氣」被導入此處 | 病灶隔離區，慢慢淨化 |
| 幽冥界 | 回收死後神魂 | 洗去記憶，重入輪迴 |

修士體內靈氣濃度高過所在界面時，就會「浮」到上一個氣泡，這就是飛昇。UP 主也用這套模型解釋修士能飛、界面重力相同、日月繞星球運行等設定。

## 時間線

### 仙界：遠古（不知多少億年前）
- **第十九代天庭至尊古道神**與「天道七君」共掌天道。七君中三位是心腹：天魔道祖隱明（渡劫時的域外天魔與心魔都是他的分身）、預言道祖陳摶（一生只能卜三十六天卦、七十二地卦，用完即被天道吞噬）、土之本源道祖軒轅杰；另有火之本源赤融、水之本源陳如煙，一席空缺。
- 古道神悟出天道沒有意識，卻被自己斬出的**自我屍奪舍**，成為古或今。古或今想用「三千道神大陣」以混沌法則覆蓋天道、自己成為有意識的天道。
- **天道的兩步反擊**：一是把「遁去的一」凝成掌天瓶；二是後來讓瓶子生出瓶靈。
- **李元究**（偽靈根）撿到掌天瓶，悟出天人合一，仿造出許多仿製小瓶，成為金之本源道祖、創九元觀，為了宗門存續接受邀請補入天道七君。
- **彌羅老祖**不靠瓶子，憑天賦悟出至尊法則與五行的關係，把真言門的大五行幻世訣修到大羅。

### 仙界：上一條時間線的韓立 → 輪迴殿主
- 掌天瓶後來被偷離九元觀（字幕稱偷瓶者為「骷髏」，原著名稱未確認），輾轉落到剛飛昇的韓立手中，他的道侶是甘如霜。
- 這個韓立從瓶中悟出宇宙構造，計畫成為輪迴道祖：先到幽冥界擊殺冥王（冥王轉世為後來的刑獸），再到灰界組織激進派，建立輪迴域反攻天庭。
- 一切都在擁有預言道祖的古或今算計之內：古或今利用他替自己收集輪迴法則與灰界的稀有法則。
- 甘如霜生下女兒後，古或今來襲。甘如霜自爆輪迴法則之力掩護，韓立往掌天瓶灌入時間法則想自爆，**意外讓瓶子生出瓶靈**——UP 主認為這正是天道等待的時刻。
- 這個韓立回到更早的時間，重修輪迴法則，成為**輪迴殿主**，重新布局：把冥王轉世安排到新韓立身邊當靈獸；調停魔域夜陽王朝內鬥，讓魔君石空解（蟹道人）把本源封入傀儡；百萬年前讓灰界輪迴域入侵冥寒仙域；勸彌羅老祖赴死，並在幽冥界為他留下傳承之地；讓偷瓶者在空間裂縫中被踹到靈界、瓶子落入虛空。
- UP 主認為瓶靈看穿輪迴殿主和古或今本質相同，最終一定讓他輸。

## UP 主的人界社會觀察
- **資源池死局**：飛昇斷絕後，所有人困在同一個池子裡，資源只夠養固定數量的元嬰，一人上去就要一人下來，這才是正魔之爭的根源（UP 主援引作者忘語的訪談說法）。
- **魔功分類**：「上古、普通」是時間維度的兩代產品，「頂級」是威力標籤，兩者不是同一套排序。魔功的真正誘惑是「魔氣灌體」暴漲修為，代價是神智喪失。

## 做遊戲時可借鑑的點（類型通用的部分）
- **「遁去的一」當作世界的變數**：大衍之數是公共的易經概念，很適合當作「主角為什麼能改變命運」的世界觀理由。
- **界面分層的物理解釋**：用清濁之氣分層，一次解釋飛昇、界面差異、異界功能。
- **時間線疊加**：主角的未來版本回到過去布局，適合 Roguelike 的輪迴敘事（見 [[分魂與化身]]）。
- **資源池死局**：用有限資源解釋勢力衝突，比「正邪之分」更有層次。
- **遺忘的使命**：守封印的宗門忘了為什麼要守，是很好的劇情伏筆。
