# 《凡人修仙傳》補全設定、作者邏輯與角色塑造

> [!warning] 參考用，不可照搬
> 這篇是研究筆記，記錄忘語作品的專屬設定與人物。自己的遊戲只借用「做法」，名稱、人物、劇情都要重新設計，見 [[避免照搬清單]]。

> [!note] 查證程度
> 既有的 [[凡人修仙傳]] 筆記偏重仙界篇與機制，這篇補的是**正傳人界、靈界的故事骨架與人物**。內容依原著記憶整理，網路上找不到忘語本人談角色設計的訪談（查到的都是電視劇導演的說法），所以「作者邏輯」一節是我從作品結構歸納的。標 `（待查證）` 的細節，之後可用 Liam 手上的全本文字檔核對。

5W 的用法：每個設定或角色都問 **Who**（誰）、**What**（是什麼）、**When**（出現在故事哪個階段）、**Where**（在哪裡）、**Why**（作者為什麼需要它），必要時加 **How**（怎麼運作、怎麼寫出來）。其中 **Why** 最重要，它就是作者的邏輯。

## 一、補全：既有筆記缺的設定

### 1. 靈根與「偽靈根」

| 問 | 答 |
| --- | --- |
| Who | 所有想修仙的凡人；韓立是四屬性偽靈根 |
| What | 靈根決定吸納靈氣的速度。單一屬性的天靈根最好，屬性越雜越差；四、五屬性叫偽靈根，幾乎被宗門放棄。另有風、雷、冰等異靈根 |
| When | 故事最開頭，入門測試時就判定 |
| Where | 七玄門的測試、黃楓谷的升仙大會 |
| Why | 把主角釘死在「資質最差」的起點，讓之後的每一步都需要解釋：靠什麼補？答案是丹藥，丹藥需要靈藥，靈藥需要年份，於是引出掌天瓶。資質差是整條因果鏈的起點 |
| How | 資質差的代價寫得很具體：修煉慢、被分去管藥園當雜役、師長不重視、壽元可能撐不到突破 |

### 2. 凡俗到仙途的入口：江湖門派與升仙令

| 問 | 答 |
| --- | --- |
| Who | 韓立、三叔、墨大夫、七玄門弟子 |
| What | 韓立先進的是凡人江湖門派七玄門，不是修仙宗門。之後靠一枚「升仙令」才拿到黃楓谷升仙大會的資格 |
| When | 第一卷，韓立十歲出頭到青年 |
| Where | 越國鏡州，七玄門在彩霞山 |
| Why | 先讓讀者在凡人江湖待一段，建立「凡人有多脆弱」的體感，再跨進修仙界，落差才大。升仙令是「門票制」：仙途不是靠努力就能進，要先有門路，這也是資源稀缺的第一層 |
| How | 江湖篇的危險不是妖魔而是人心：墨大夫想奪舍、野狼幫攻山。修仙界的冷酷在江湖篇就先預演了 |

升仙令由越國七派製作，賜給立過奇功的修仙家族，持令者不論是誰都能入門並得一枚築基丹。韓立十八歲時殺了攜令出逃的金光上人，奪得這枚升仙令。

### 3. 築基丹：第一道資源瓶頸

| 問 | 答 |
| --- | --- |
| Who | 黃楓谷所有煉氣期弟子 |
| What | 築基丹能大幅提高築基成功率，主藥只在血色禁地採得到，宗門數量有限 |
| When | 第一卷後半，韓立在宗門的第一個大目標 |
| Where | 血色禁地（越國七派共同的試煉地） |
| Why | 用一顆丹把「資源有限 → 要搶 → 搶就會死人」講得一清二楚。這是全書資源池邏輯的縮小版，也讓宗門的冷血有了理由：宗門用弟子的命換靈藥，再用丹藥篩出值得培養的人 |
| How | 禁地只准低階弟子進、修為受限、弟子互殺；靈藥交給宗門才能換丹。韓立的特殊之處在於他手上有催熟靈藥的瓶子，所以能私下多留一手 |

### 4. 天南與正魔大戰

| 問 | 答 |
| --- | --- |

| How | 種族政治取代宗門政治：結盟、血脈、真靈遺骸。魔界入侵則提供大規模戰爭與「敵人不是純惡」的反轉，見既有筆記的魔界一節 |

## 二、忘語的設計邏輯（本筆記的歸納）

### 邏輯 1：一切從「資源稀缺」推出來

全書最底層的假設是：**修仙資源永遠不夠分**。由此推出：
- 宗門會犧牲弟子（築基丹、血色禁地）
- 修士會互相殺害（殺人奪寶）
- 正魔會打仗（元嬰名額有限）
- 魔界會入侵（要搶地盤當退路）
- 道祖會追殺同道（同一條大道的道祖之位有限）

從人界到仙界，衝突的尺度一直變大，但邏輯是同一條。這是凡人的世界觀最「穩」的原因：讀者不用接受新的動機，只要接受更大的池子。

### 邏輯 2：主角的外掛只解決一件事

掌天瓶只能催熟靈藥，它**不能**幫韓立打架、不能提高資質、不能保命。所以：
- 韓立有丹藥，但仍然打不過同階天才，只能靠準備、偷襲、逃跑。
- 外掛必須藏好，一旦曝光就是殺身之禍，於是「謹慎」從性格變成生存必需。

這是「凡人流」和一般「外掛流」的分界：外掛給的是**資源**而不是**勝利**，主角仍然要自己做選擇。

### 邏輯 3：境界壓制是硬規則，越級要付代價

書中很少讓主角輕鬆越級。韓立贏高階對手時，通常是：事前布陣、用一次性寶物、利用對方輕敵、或者乾脆逃。每次越級都有代價（精血大損、法寶毀掉、閉關好幾年）。規則硬，勝利才有重量。

### 邏輯 4：地圖副本式結構，每卷重置一次

| 階段 | 地圖 | 主角身分 | 重置了什麼 |
| --- | --- | --- | --- |
| 1 | 七玄門 | 江湖記名弟子 | 從凡人進入半個修仙者 |
| 2 | 黃楓谷 | 宗門弟子 | 有了師門靠山 |
| 3 | 亂星海 | 散修 | 失去靠山，自力更生 |
| 4 | 天南、大晉 | 宗門長老、元嬰老怪 | 從被保護者變成保護者 |
| 5 | 靈界 | 飛昇新人 | 再次變弱 |
| 6 | 靈寰界、仙界 | 失憶重修 | 連記憶都歸零 |

每換一張地圖，舊的人際網就斷掉，配角大多留在原地。這解釋了為什麼凡人「配角很多、留得很少」：不是作者無情，而是結構本身就是一張一張的副本。

### 邏輯 5：時間差製造生離死別

修士壽元差距極大，韓立閉關一次就是幾十、上百年。凡人朋友會老死，資質差的同門會坐化，能跟上的只有少數。作者很少用「戰死」來告別配角，更常用的是「回頭發現對方已經老了、死了」。這種告別是修仙世界獨有的，也是凡人最動人的地方。

### 邏輯 6：沒有純善純惡，只有立場和利益

墨大夫對韓立有恩又想奪舍；魔族入侵卻對凡人留手；輪迴殿主幫主角其實是在下自己的棋。作者寫人的方式是：**先給每個人一個合理的私心，再看私心之間怎麼碰撞**。

### 邏輯 7：超長伏筆

「小綠瓶」在第一章撿到，到仙界篇最後一章才把它的真相（天道留下的變數）和結局（瓶碎、吸走道祖本源）收完。中間每隔幾百章揭露一點：能催熟、有瓶靈、能逆轉時間。伏筆回收得慢，讀者才會一直追。

### 邏輯 8：感情克制

韓立的感情線多半是「錯過」和「不說」：陳巧倩單戀、紫靈與元瑤各有牽掛、南宮婉是唯一的道侶但聚少離多。作者把「仙路漫漫，情是負擔也是軟肋」當成主題，所以感情寫得很淡，淡才顯得真。

## 三、主要角色塑造（5W＋How）

每個角色最後一欄「可借鑑」只寫**類型通用的做法**，不是人物本身。

### 韓立（主角）

| 問 | 答 |
| --- | --- |
| Who | 越國山村的貧家少年，小名「二愣子」，四屬性偽靈根 |
| What | 從凡人修到時間道祖，最後主動跌回大羅巔峰 |
| When | 貫穿全書：正傳 2,446 章、仙界篇 1,394 章 |
| Where | 人界越國 → 黃楓谷 → 亂星海 → 天南、大晉 → 靈界 → 靈寰界 → 仙界各域 |
| Why | 作者需要一個「讀者可以代入的普通人」：不聰明絕頂、不英俊、不天才，只是比別人更小心、更能忍、更肯準備。他是「資源稀缺世界」裡最合理的生存者 |
| How | 性格是**被經歷一層層壓出來的**：墨大夫教會他人心險惡；築基丹教會他資源要自己留；亂星海教會他不靠組織；生離死別教會他把感情藏起來 |

韓立的性格公式：
- **謹慎**：先查地圖、先布陣、先準備退路；寶物不輕易示人。
- **重利但有底線**：會殺人奪寶，但會報恩、守承諾（替墨大夫照顧家人、照顧厲飛雨）。
- **不爭虛名**：能躲就躲，能交易就不打。
- **長線思考**：一次閉關、一爐丹動輒幾十年，他願意等。

可借鑑：主角的性格最好從**世界規則**推出來，而不是先設定一個性格再找事件來配。

### 墨大夫（墨居仁）

| 問 | 答 |
| --- | --- |
| Who | 七玄門的神醫，韓立的第一個師父 |
| What | 收韓立為記名弟子、教他長春功，真正目的是養一具資質合適的身體來奪舍 |
| When | 第一卷開頭 |
| Where | 七玄門彩霞山 |
| Why | 他是全書的「第一課」：最先對你好的人，可能就是最想害你的人。作者用他一次建立兩件事：修仙界的殘酷，以及韓立「不輕信」的起源 |
| How | 先寫恩（收徒、教功法、照顧），再寫疑（逼服屍蟲丸、不教武功），最後揭底（奪舍）。死前託付家人，讓他不是純反派，韓立也因此背上一份恩情與承諾 |

可借鑑：「恩師即反派」的第一個 Boss，能在序章同時教玩家規則和定下主角性格。

### 厲飛雨

| 問 | 答 |
| --- | --- |
| Who | 七玄門弟子，韓立在凡人時期唯一的朋友 |
| What | 為了快速變強服用損壽的秘藥（抽髓丸），韓立替他保密、配藥 |
| When | 第一卷登場；韓立結嬰後回鄉（第六百六十二章〈四叔祖〉），兩人再也沒見過面 |
| Where | 七玄門 |
| Why | 他代表「韓立沒走上的那條路」：凡人用壽命換力量。韓立當年留下的丹藥也救不了他，厲家先祖「英年早逝」。作者用他給讀者一個仙凡之隔的參照 |
| How | 先寫少年意氣的友情，再用兩百年的時間跳躍：韓立回鄉時只見到厲家後人，還發現厲飛雨的子女和韓家結成了世交。韓立認了後人、了卻塵緣就走。之後他在天南行走時化名「海外散修厲飛雨」（第九百四十五章〈玉佩〉），斬心魔劫時心魔也幻化成厲飛雨（第兩千一百八十五章〈斬心魔〉）。朋友不在了，名字一直跟著他 |

可借鑑：序章的朋友不必戰死，**讓主角回來時只見到他的後人**，比戰死更能表現時間差；再讓主角借用他的名字，告別就變成了長久的紀念。

### 張鐵

| 問 | 答 |
| --- | --- |
| Who | 與韓立同時被墨大夫收的記名弟子 |
| What | 練象甲功，後來「失蹤」：墨大夫想奪舍他卻出了差錯，把他煉成傀儡。韓立殺墨大夫後留下這具傀儡，改名「曲魂」，再以玄陰訣煉成身外化身、提升到結丹期；後來曲魂在荒島洞府被老怪玄骨奪舍，最終在虛天殿爭鼎時，玄骨連同曲魂之身被韓立的乾藍冰焰燒成灰燼 |
| When | 第一卷 |
| Where | 七玄門 |

## 四、角色塑造的共通手法

| 手法 | 例子 | 效果 |
| --- | --- | --- |
| 先恩後疑再揭底 | 墨大夫、輪迴殿主 | 讓讀者跟主角一起學會不輕信 |
| 用時間告別 | 厲飛雨、凡人親友 | 修仙世界特有的悲劇 |
| 天賦即負擔 | 紫靈的美貌、韓立的瓶子 | 角色的優點自動產生衝突 |
| 配角有自己的主線 | 元瑤、寶花 | 世界顯得比主角大 |
| 夥伴三段成長 | 金童、啼魂、銀月 | 工具 → 個體 → 身世 |
| 強敵先合作 | 極陰祖師、寶花 | 張力持久，不必立刻打 |
| 反派用制度出場 | 古或今與天庭 | 最強者不必出手也有壓迫感 |
| 性格由經歷壓出 | 韓立 | 主角的選擇有因果，讀者信服 |

## 五、轉化到本作時可以問的問題

用同樣的 5W 問自己的角色，尤其是 Why：
- 本作的「資源稀缺」是什麼？（例如秤碑、靈脈？）
- 主角的優勢只解決哪一件事？它曝光了會怎樣？
- 每張地圖重置了主角的什麼？
- 哪個配角會用「老去」告別？
- 誰是「主角運氣好」背後的布局者？
